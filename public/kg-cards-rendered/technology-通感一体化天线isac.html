通感一体化天线ISAC

ISAC天线是让一套硬件同时干两件事——发通信信号给人类用户，又用同一套波束去探测环境里的障碍物、车辆、行人，实现"一边聊天一边看路"。

1.1 什么是ISAC

通信感知一体化（Integrated Sensing and Communication，ISAC）是6G的六大典型应用场景之一。它把传统独立的通信系统和雷达感知系统融合到同一个物理平台上，共享天线阵列、频谱资源、信号处理链路，实现"一网两用"。

核心思想：通信波形本身就是感知波形。5G/6G基站发射的OFDM信号，在传输数据的同时，其时延、多普勒频移、到达角等信息，恰好可以被接收机用来估计目标的距离、速度和角度。

1.2 为什么需要ISAC

  • 频谱效率：通信和感知各自占用独立频谱，浪费严重。ISAC共享频谱，效率翻倍
  • 硬件成本：两套系统等于两套天线、射频链、基带处理。融合后只需一套
  • 6G需求：自动驾驶、无人机、数字孪生需要高精度环境感知，光靠独立雷达成本高、部署难

1.3 天线角色的转变

传统天线是"能量转换器"，负责把电信号变成电磁波（或反之）。ISAC天线变成了"电磁波空间信息处理器"：

  • 发射端：生成兼具通信高效率和高感知分辨率的波形
  • 接收端：同时分离通信信号和解调数据，以及感知回波和提取环境信息

2.1 大规模MIMO阵列的空间自由度

ISAC的核心使能技术是大规模MIMO阵列。传统MIMO可能只有4-8个天线单元，ISAC系统通常部署数十到数百个单元。

空间自由度公式：

对于均匀线阵ULA，有N个天线单元，阵元间距d=λ/2：

方向图函数：F(θ) = Σ(n=0 to N-1) w_n · exp(j·n·π·sin(θ))

其中w_n是波束赋形权重，θ是波束指向角。N越大，主瓣越窄，角度分辨率越高，感知精度越好。

2.2 波束赋形架构

ISAC需要同时服务多个用户和感知多个目标，波束赋形是关键：

混合波束赋形（Hybrid Beamforming）：

RF域（模拟）：相移器网络 → 低维波束
BB域（数字）：数字预编码 → 高维波束
  • 模拟波束：覆盖 wide area，适合感知扫描
  • 数字波束：指向 specific user，适合通信传输
  • 两者协同：通信波束指向用户A，感知波束指向目标B，同时工作互不干扰

2.3 自干扰抑制

ISAC最棘手的工程挑战。发射机的高功率信号会通过天线近场耦合、散射泄漏到接收机：

自干扰功率 ≈ 发射功率 × 耦合系数
典型值：发射功率 40dBm，耦合系数 -60dB → 自干扰 -20dBm
感知回波功率：-90dBm ~ -110dBm

自干扰比感知回波强70-90dB，必须抑制到噪声基底以下。

抑制手段：

  • 模拟域隔离：极化隔离、空间正交波束、去耦网络
  • 数字域消除：自干扰信道估计 + 减法消除
  • 全双工技术：时域/频域/空域分离

2.4 稀疏MIMO阵列

传统紧凑MIMO：N个单元占据 N×λ/2 孔径 稀疏MIMO：N个单元占据更大孔径，用空穴换分辨率

孔径增益：

方向图主瓣宽度 ≈ λ / (N·d)
稀疏阵 d > λ/2 → 主瓣更窄 → 角度分辨率更高

代价：栅瓣问题（grating lobe），需要在阵列优化中约束栅瓣电平。

3.1 天线架构类型

类型 描述 优点 缺点
分离式阵列 通信天线和感知天线物理隔离 设计简单，自干扰易抑制 空间资源未完全共享
共形阵列 天线单元集成到载体曲面 高度集成，隐蔽性好 耦合复杂，设计难度大
可重构阵列 通过开关/变容管动态切换模式 灵活适应不同场景 插入损耗，非线性

3.2 频段选择

频段 典型应用 优势 挑战
Sub-6GHz 广域通信 + 粗粒度感知 覆盖远，技术成熟 分辨率低
mmWave (24-100GHz) 高精感知 + 高速通信 带宽大，阵列紧凑 路径损耗大
THz (>100GHz) 超高分辨率感知 极致带宽 器件不成熟，损耗极大

3.3 波形设计

OFDM波形：5G/6G原生波形，天然适合感知 - 时延分辨率：Δτ = 1/B（B为信号带宽） - 速度分辨率：Δv = λ/(2·T_obs)（T_obs为观测时间） - 角度分辨率：Δθ ≈ λ/(N·d·cos(θ))

LFM（线性调频）波形：传统雷达波形，感知性能好 - 距离分辨率：ΔR = c/(2B) - 缺点：与通信标准不兼容

联合优化波形：通信效率和感知性能 Pareto 最优折中

4.1 自动驾驶

车载ISAC天线同时实现：

  • V2X通信：与周围车辆、基站交换信息
  • 环境感知：探测前方车辆、行人、障碍物位置和速度

华为在MWC26展示的V2X感知方案即基于此原理。

4.2 低空经济

无人机/低空飞行器搭载ISAC：

  • 通信：与地面基站保持链路
  • 感知：避障、地形测绘、其他飞行器检测

4.3 卫星通感一体化

多低轨卫星搭载ISAC基站，协同为地面用户提供：

  • 通信服务：覆盖偏远地区
  • 感知服务：环境监测、灾害预警

长光卫星2026年7月发表的研究提出了多卫星联合波束成形方案，通过半正定松弛优化最大化最小检测概率。

4.4 智慧城市

建筑物外墙ISAC天线：

  • 通信：为周边用户提供5G/6G接入
  • 感知：交通流量监测、人流密度统计、异常行为检测

5.1 通信性能指标

  • 频谱效率：bit/s/Hz（目标：10-100 bit/s/Hz for 6G）
  • 误码率BER：< 1e-5（QPSK），< 1e-3（16QAM）
  • 信噪比SNR：> 20dB（保障高阶调制）

5.2 感知性能指标

  • 距离分辨率：ΔR = c/(2B)，6GHz带宽100MHz → 1.5m
  • 角度分辨率：Δθ ≈ λ/(N·d)，128阵元@28GHz → ~2°
  • 速度分辨率：Δv = λ/(2·T_obs)，1s观测 @ 28GHz → 5.4mm/s
  • 探测距离：取决于发射功率、天线增益、目标RCS

5.3 自干扰抑制比（SIRR）

SIRR = P_tx_coupling - P_echo_target
目标：> 80dB（确保回波可检测）

5.4 感知-通信权衡因子

定义感知性能度量（如CRB，克拉美-罗下界）与通信容量之比：

Trade-off Factor = f(CRB_sensing, C_communication)

最优设计需要 Pareto 前沿分析。

6.1 自干扰消除难度被低估

很多研究假设自干扰可以完美消除，实际工程中：

  • 模拟域抑制有限（通常30-50dB）
  • 数字域消除依赖精确的信道估计
  • 温度漂移、器件老化会改变耦合特性
  • 需要在线校准机制

6.2 波形兼容性难题

5G NR和6G标准没有原生支持感知功能，要：

  • 修改波形参数（子载波间隔、CP长度）
  • 增加感知参考信号（Probe Signal）
  • 与现有终端兼容

6.3 阵列校准复杂度

大规模MIMO阵列每个通道的相位和幅度必须精确校准：

  • 工厂校准：成本高，一次性的
  • 在线校准：需要辅助信道，消耗资源
  • 温度漂移：每度变化引起相位漂移

6.4 算法复杂度

联合波束成形是NP-hard问题，近似算法才有可行性：

  • 交替优化（AO）：收敛但慢
  • 凸松弛（SDR）：高质量解但计算量大
  • 深度学习：训练难，泛化性存疑

7.1 第一阶段：通信增强感知（2020-2025）

  • 5G AAU增加感知功能
  • 通信波形复用做粗粒度感知
  • 代表：华为V2X感知方案

7.2 第二阶段：联合设计优化（2025-2030）

  • 波形、波束、功率联合优化
  • 稀疏MIMO阵列实用化
  • 代表：3GPP Rel-19/20 ISAC标准化

7.3 第三阶段：原生ISAC（2030+）

  • 6G标准原生支持感知
  • 通感算一体化（ISACC）
  • 卫星-ISAC深度融合
  • 代表：清华SC-RIS、卫星通感算融合架构

9.1 稀疏MIMO成为主流

紧凑MIMO走向瓶颈，稀疏MIMO用更少单元实现更大孔径，性价比更高。

9.2 可重构ISAC天线

通过智能超表面RIS或可调器件，动态切换通信/感知模式，适应场景变化。

9.3 卫星-ISAC融合

低轨卫星星座搭载ISAC基站，实现全球三维立体覆盖，地面-天空感知一体化。

9.4 AI赋能ISAC

深度学习用于：

  • 波束成形快速求解
  • 自干扰信道估计
  • 感知-通信波形联合优化

9.5 太赫兹ISAC

THz频段提供超大带宽，实现厘米级甚至毫米级感知分辨率，但器件和传播挑战巨大。
