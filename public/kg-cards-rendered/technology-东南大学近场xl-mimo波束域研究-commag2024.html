东南大学近场XL-MIMO波束域研究-COMMAG2024

东南大学王承祥教授团队在IEEE Communications Magazine发表的超大规模MIMO近场通信综述，提出基于分数阶傅立叶变换的近场波束空间划分方法，揭示近场波束聚焦能力在角度域随天线数线性增长、距离域随天线数二次增长的规律，为6G XL-MIMO系统设计提供理论框架。

1.1 XL-MIMO与近场效应

XL-MIMO（Extremely Large-scale MIMO）是6G关键技术：

  • 天线单元数：数百至数千
  • 阵列孔径：数米至数十米
  • 工作频段：毫米波/太赫兹

近场效应产生条件：

瑞利距离：R_Fresnel = 2D²/λ
其中 D = 阵列孔径，λ = 波长

当用户距离 R < R_Fresnil 时，进入近场区域：

  • 波前从平面波变为球面波
  • 不同距离的用户有不同的波前曲率
  • 传统远场波束赋形失效

1.2 波束空间理论

核心思想：将近场信道从天线空间变换到波束空间，简化分析和设计。

数学工具：分数阶傅立叶变换（FrFT） - 传统傅立叶变换：时域↔频域 - 分数阶傅立叶变换：时域↔任意中间域 - 在近场MIMO中：天线空间↔波束空间（含距离信息）

波束空间划分：

  1. 高主瓣区：波束增益高，适合通信
  2. 低主瓣区：波束增益低，适合干扰抑制
  3. 旁瓣区：波束增益很低，适合噪声抑制

2.1 分数阶傅立叶变换（FrFT）

定义：

F_α[f(t)] = ∫ K_α(t,τ) f(τ) dτ
其中 K_α 是 FrFT 核函数，α = θ/π 是变换阶数

在近场MIMO中的应用：

  • 角度信息：对应传统傅立叶变换（α=1）
  • 距离信息：对应分数阶（0<α<1）
  • 联合角度-距离：对应分数阶（α≠1）

2.2 近场波束空间划分

高主瓣区特性：

  • 波束增益高，信噪比好
  • 近似高斯分布，便于信号处理
  • 适合波束对准和跟踪

低主瓣区特性：

  • 波束增益低，干扰小
  • 适合干扰抑制和波束训练
  • 可减少训练开销

旁瓣区特性：

  • 波束增益很低
  • 适合噪声建模和校准

2.3 波束聚焦能力分析

关键发现：

维度 聚焦能力增长 含义
角度域 线性增长（∝N） 增加天线数可线性提升角分辨率
距离域 二次增长（∝N²） 增加天线数可二次提升距离分辨率

物理意义：

  • 距离域分辨率提升更快，是因为近场波前的球面曲率提供了额外自由度
  • 这为6G超高速率提供了理论保证

2.4 应用方向

波束训练：

  • 利用低主瓣区减少训练次数
  • 利用高主瓣区实现快速对准

波束跟踪：

  • 基于高主瓣区覆盖范围分析
  • 设计高效跟踪算法

感知与定位：

  • 综合利用高低主瓣区
  • 实现厘米级定位精度

信道估计：

  • 利用波束空间平移不变性
  • 开发高效估计算法

方法 原理 优点 缺点

4.1 6G基站设计

场景：

  • 超大规模天线阵列（1000+单元）
  • 覆盖半径：100-500m
  • 用户分布：密集城区

应用：

  1. 波束空间划分指导天线布局
  2. 高主瓣区用于服务近场用户
  3. 低主瓣区用于干扰抑制

4.2 卫星互联网终端

场景：

  • 低轨卫星（500-1200km）
  • 终端天线阵列（数百单元）
  • 高速移动（0-10km/s）

应用：

  1. 近场波束跟踪卫星
  2. 波束空间快速切换
  3. 多波束同时服务

4.3 车联网V2X

场景：

  • 路侧单元（RSU）
  • 车辆高速移动
  • 密集交通环境

应用：

  1. 近场波束聚焦车辆
  2. 波束空间快速切换
  3. 干扰抑制提升可靠性

4.4 工业互联网

场景：

  • 工厂内部通信
  • 大量传感器和设备
  • 高可靠低延迟要求

应用：

  1. 近场波束定向服务
  2. 波束空间多用户复用
  3. 感知一体化支持定位

5.1 波束性能

指标 数值 条件
角度分辨率 λ/(ND) N=天线数，D=单元间距
距离分辨率 R²/(Nλ) R=距离
波束宽度（角度） ~λ/(ND) 3dB宽度
波束宽度（距离） ~R²/(N²λ) 3dB宽度
主瓣增益 10log₁₀(N) + G_element dBi

5.2 系统性能

指标 数值 说明
频谱效率 ~N log₂(1+SNR) 随N线性增长
能量效率 ~log₂(1+SNR)/P_total 需优化功耗
定位精度 ~R/(N√SNR) 厘米级潜力
感知分辨率 ~λ/(2ND) 毫米级潜力

5.3 算法复杂度

算法 复杂度 说明
FrFT O(N log N) 快速算法
波束空间划分 O(N²) 矩阵运算
波束训练 O(N log N) 分层搜索
信道估计 O(N²) 矩阵求逆

6.1 硬件挑战

大规模阵列校准：

  • 问题：数百单元相位一致性难以保证
  • 解决：内嵌校准电路，定期校准

波束空间计算复杂度：

  • 问题：FrFT计算量大
  • 解决：GPU加速，或近似算法

6.2 算法挑战

信道状态信息（CSI）获取：

  • 问题：近场CSI维度高，获取困难
  • 解决：波束空间压缩感知

用户移动跟踪：

  • 问题：高速移动导致波束失配
  • 解决：预测性波束跟踪

6.3 标准化挑战

3GPP标准滞后：

  • 问题：Rel-18/19尚未完全覆盖近场
  • 解决：积极参与标准制定

测试方法缺失：

  • 问题：近场测试方法不统一
  • 解决：推动测试标准制定
