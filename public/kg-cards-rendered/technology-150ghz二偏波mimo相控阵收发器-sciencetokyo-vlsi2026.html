150GHz二偏波MIMO相控阵收发器-ScienceTokyo-VLSI2026

东京科学大学团队在VLSI 2026会议上发表的世界首个150GHz二偏波MIMO相控阵无线IC，采用65nm CMOS工艺，芯片仅3x4mm，单偏波124mW发射/90mW接收，搭载后实现20x8.2mm AiP模块，EIRP达27.8dBm/26.3dBm，±45°波束扫描，实测144Gbps 3m通信，50m远景。这是6G亚太赫兹终端芯片的里程碑级突破。

天线技术技术概念相控阵封装天线6G太赫兹毫米波

1.1 技术背景

6G通信的目标是100Gbps以上的超高速无线传输，而实现这一目标的核心路径是占用更宽的频谱。当前5G最高使用毫米波（30-300GHz），而6G的候选频段是亚太赫兹（100-300GHz），特别是150GHz频段（D波段），具有数百MHz甚至GHz级的可用带宽。

然而，亚太赫兹频段面临两个核心挑战：

  1. 自由空间路径损耗（FSPL）极大：频率越高，损耗越大，150GHz的FSPL比28GHz高出约30dB
  2. 器件尺寸急剧缩小：150GHz波长约2mm，天线间距需≤1mm，电路难以集成

传统解决方案是相控阵技术：用多个天线单元组成阵列，通过电子控制各单元的相位，实现波束指向的灵活调整。但这要求每个天线单元配备独立的射频链（功率放大器、移相器等），导致功耗和面积急剧增加。

1.2 核心突破：收发共享架构

本研究的核心创新在于提出了收发信号路径部分共享的电路架构：

  • 传统设计：发射和接收路径完全独立，需要额外的切换开关
  • 本方案：省略部分切换开关，在 antenna 直前的信号路径上实现收发共享
  • 效果：回路面积减少约50%，同时保持切换时的低信号损耗

此外，针对亚太赫兹相控阵必需的中间频率（IF）放大器，传统设计在宽带化时会引入大量无源元件（电感、电容），大幅增加面积。本团队设计了独特电路结构，在原来一半以下的面积内实现了20GHz以上的宽带工作。

2.1 天线封装集成（AiP）技术

封装天线（Antenna-in-Package, AiP）是将天线直接集成在芯片封装内的技术。对于150GHz这种亚太赫兹频段，传统PCB走线损耗极大，必须采用AiP方案：

  1. 天线单元设计：在封装基板内埋入微带天线或偶极子天线
  2. 信号路径最短化：芯片引脚直接连接到天线单元，最小化传输线长度
  3. 散热设计：亚太赫兹功耗密度高，需考虑热管理

本研究的AiP模块将两个150GHz射频IC（分别负责垂直和水平偏波）集成在20×8.2mm的封装内，每个偏波配置4个天线单元，形成8单元二维相控阵。

2.2 二偏波MIMO架构

多输入多输出（MIMO）技术利用多个天线同时传输多个数据流，提升容量。本研究采用二偏波MIMO：

  • 垂直偏波（V-pol）和水平偏波（H-pol）各4个天线单元
  • 两个偏波独立传输数据流，频谱效率翻倍
  • 偏波隔离度需>20dB，避免交叉干扰

与传统极化分集相比，二偏波MIMO在亚太赫兹频段的优势在于：

  1. 波长短（2mm），可在小面积内实现足够间距
  2. 偏波正交性好，隔离度高
  3. 无需额外的频率/时隙资源

2.3 相控阵列波束赋形

波束赋形（Beamforming）是相控阵的核心功能：

  1. 数字波束赋形：每个天线单元有独立的ADC/DAC，灵活但功耗高
  2. 模拟波束赋形：用移相器和功率分配器，功耗低但灵活性差
  3. 混合波束赋形：折中方案，本方案采用此架构

本研究的150GHz相控阵采用全模拟波束赋形：

  • 每个天线单元配备移相器（phase shifter）
  • 通过控制各单元相位差，实现波束指向的电子调节
  • ±45°扫描范围覆盖典型室内通信场景

  • 成本低（大规模半导体产线）
  • 面积小（65nm工艺）
  • 功耗低（可集成大量单元）
  • 兼容数字电路（SoC集成潜力）

3.2 发射链架构

数字基带 → DAC → IF放大器 → 上变频 → 功率放大器 → 移相器 → 天线单元
                                                              ↓
天线单元 ← 移相器 ← 低噪声放大器 ← 下变频 ← IF放大器 ← 混频器 ← ADC ← 数字基带

关键设计点：

  1. IF放大器：20GHz以上宽带，面积减半
  2. 混频器共享：收发共用部分混频器，减少面积
  3. 功率放大器：124mW/单元，EIRP达27.8dBm
  4. 移相器：分辨率需≤5°，保证波束指向精度

3.3 封装级设计

AiP封装采用有机基板+ silicon interposer混合方案：

  1. 基板层：铜微带线，低损耗
  2. 中介层：硅通孔（TSV）实现高频互连
  3. 天线层：蚀刻铜天线单元，波长匹配

4.1 6G室内超高速通信

核心场景：

  • 室内热点：办公室、商场、场馆，峰值速率需求>100Gbps
  • 扩展现实（XR）：AR/VR头显无线串流，需要极低延迟和超高带宽
  • 全息通信：全息投影需要TB级数据速率

优势分析：

  1. 150GHz频段带宽充足，支持多Gbps用户数
  2. 相控阵波束赋形克服高路径损耗
  3. 二偏波MIMO频谱效率翻倍
  4. AiP小型化，适合终端设备

4.2 无线回传与 Fronthaul

固定无线接入（FWA）：

  • 5G基站回传：10Gbps+速率需求
  • 小区间互联：点对点/点对多点链路
  • 应急通信：快速部署的无线连接

** fronthaul场景**：

  • CPRI/eCPRI协议承载
  • 低延迟要求（<100μs）
  • 150GHz相控阵可实现远距离点对点连接

4.3 卫星互联网终端

低轨卫星通信：

  • Starlink V2mini已使用相控阵天线
  • 150GHz频段可用于星地链路
  • 小型化终端需求强烈

优势：

  • 相控阵电子扫描，无需机械转向
  • 二偏波提升链路冗余
  • AiP封装抗振动、重量轻

4.4 工业物联网与远程操作

场景：

  • 远程手术：超高清晰视频回传
  • 工业自动化：机器人协同控制
  • 智能工厂：海量传感器数据回传

要求：

  • 可靠性：50m通信距离满足厂房覆盖
  • 延迟：亚太赫兹低延迟特性
  • 容量：144Gbps满足多路4K/8K视频

6.1 工艺挑战

CMOS亚太赫兹设计的固有难题：

  1. 寄生参数影响大：150GHz下，导线电感和电容的寄生效应显著
  2. 衬底损耗高：硅衬底在太赫兹频段损耗大，需高阻硅或SOI
  3. 匹配网络复杂：宽带匹配难，需多节匹配网络

本研究的应对：

  • 采用65nm CMOS的薄氧化层，降低栅极损耗
  • 优化晶体管几何尺寸，提升fmax
  • 使用EM仿真+电路仿真联合优化

6.2 热管理挑战

高功率密度问题：

  • 单单元124mW，8单元总功耗近1W
  • 芯片面积仅12mm²，功率密度>80mW/mm²
  • 温升可能导致性能漂移

解决方案：

  • 封装级散热设计（金属散热片）
  • 动态功耗管理（空闲单元关断）
  • 温度补偿电路（自动调整偏置）

6.3 封装与互连挑战

高频信号完整性：

  1. 传输线损耗：150GHz下，铜导线损耗极大
  2. 阻抗匹配：封装互连阻抗不连续导致反射
  3. 串扰：高密度布线导致信道间干扰

本方案：

  • AiP封装内使用低损耗介质（低Dk/Df材料）
  • 阻抗连续设计，渐变过渡
  • 接地屏蔽，减少串扰

6.4 校准与测试挑战

生产测试难点：

  1. 测试设备昂贵：150GHz矢量网络分析仪价格高
  2. 校准复杂：需波导校准件，操作困难
  3. 批量一致性：工艺偏差导致性能分散

应对措施：

  • 设计内建自测试（BIST）电路
  • 自动化校准算法
  • 设计容差分析，确保批次一致性

9.1 短期（1-2年）

  1. 工艺升级：从65nm向28nm/12nm演进，提升fmax，降低功耗

  3. 多频段融合：Sub-6GHz + 毫米波 + 亚太赫兹三频段协同
  4. 应用场景落地：XR、全息通信、远程手术首批商用

9.3 长期（5年以上）

  1. 太赫兹通信普及：300GHz以上频段实用化
