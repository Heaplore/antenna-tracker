150GHz二偏波MIMO相控阵收发器-ScienceTokyo-VLSI2026

东京科学大学团队在VLSI 2026会议上发表的世界首个150GHz二偏波MIMO相控阵无线IC，采用65nm CMOS工艺，芯片仅3x4mm，搭载后实现20x8.2mm AiP模块，EIRP达27.8dBm/26.3dBm，±45°波束扫描，实测144Gbps 3m通信。这是6G亚太赫兹终端芯片的里程碑级突破。

1.1 研究背景与动机

6G通信的目标是100Gbps以上的超高速无线传输，核心路径是占用更宽的亚太赫兹频谱（100-300GHz）。150GHz频段（D波段）具有数百MHz甚至GHz级的可用带宽，但面临两大核心挑战：

  • 自由空间路径损耗极大：比28GHz高出约30dB，需要更高的发射功率或更大的阵列增益
  • 器件尺寸急剧缩小：波长仅2mm，天线间距需≤1mm，对封装和布线提出极端要求

1.2 核心技术突破

本研究提出收发信号路径部分共享的电路架构，关键创新点包括：

  1. 收发共享架构：省略切换开关，回路面积减少约50%，同时保持低信号损耗
  2. 宽带IF放大器设计：在半面积内实现20GHz以上宽带工作，解决传统设计在宽带化时引入大量无源元件的问题
  3. AiP封装集成：将天线直接集成在芯片封装内，克服150GHz下传统PCB走线损耗过大的瓶颈
  4. 二偏波MIMO架构：垂直偏波（V-pol）和水平偏波（H-pol）各4个天线单元，频谱效率翻倍

2.1 收发共享架构设计

传统相控阵收发器采用完全独立的发射和接收路径，需要额外的切换开关进行模式切换。本研究在antenna直前信号路径实现收发共享，核心优势：

  • 面积节省：回路面积减少约50%
  • 损耗降低：省去切换开关引入的插入损耗
  • IF放大器优化：传统宽带设计需大量无源元件（电感、电容），本方案在半面积内实现20GHz以上宽带工作

2.2 封装天线（AiP）技术

150GHz下传统PCB走线损耗极大，必须采用AiP方案：

  • 封装基板内埋入微带天线或偶极子天线
  • 芯片引脚直接连接天线单元，最小化传输线长度
  • 配合金属散热片进行热管理
  • 最终模块尺寸：20x8.2mm

2.3 二偏波MIMO架构

天线阵列配置：
┌─────────────────────────┐
│  V-pol: 4单元  │  H-pol: 4单元  │
│  (垂直极化)    │  (水平极化)    │
└─────────────────────────┘
总计：8单元二维相控阵

关键技术参数：

  • 偏波隔离度：需>20dB避免交叉干扰
  • 波束扫描范围：±45°
  • 全模拟波束赋形：每个天线单元配备移相器，通过控制各单元相位差实现波束指向电子调节

3.2 工艺选择

65nm CMOS工艺是亚太赫兹量产的唯一可行路径，原因：

  • 成本低：相比12nm FinFET/4nm GAA，成本优势显著
  • 面积小：适合终端设备集成
  • 功耗低：满足电池供电设备需求
  • 兼容性好：可与数字电路SoC集成

3.3 波束赋形方式

采用全模拟波束赋形，每个天线单元配备移相器，通过控制各单元相位差实现波束指向电子调节。扫描范围±45°，覆盖典型室内通信场景。

4.1 6G室内超高速通信

  • 办公室、商场、场馆峰值速率需求>100Gbps
  • 扩展现实（XR）AR/VR头显无线串流需极低延迟超高带宽
  • 全息通信需要TB级数据速率

4.2 无线回传与Fronthaul

  • 5G基站回传10Gbps+速率需求
  • 小区间点对点/点对多点链路
  • 应急通信快速部署

4.3 卫星互联网终端

  • 低轨卫星通信
  • Starlink V2mini已使用相控阵天线
  • 150GHz可用于星地链路，小型化终端需求强烈

4.4 工业物联网与远程操作

  • 远程手术超高清晰视频回传
  • 工业自动化机器人协同控制
  • 智能工厂海量传感器数据回传

6.1 路径损耗挑战

150GHz频段比28GHz高出约30dB自由空间路径损耗，必须通过以下方式补偿：

  • 高增益相控阵（8单元提供阵列增益）
  • 高EIRP发射功率（27.8dBm）
  • 低噪声接收设计（90mW功耗控制）

6.2 封装损耗挑战

传统PCB在150GHz下损耗不可接受，必须采用AiP方案：

  • 封装基板内埋入天线单元
  • 芯片引脚直接连接天线，最小化传输线长度
  • 金属散热片热管理

6.3 面积与功耗权衡

收发共享架构是关键创新：

  • 传统设计：独立收发路径 + 切换开关 → 面积大、损耗高
  • 本方案：收发共享路径 → 面积减半、损耗低
  • IF放大器在半面积内实现20GHz以上宽带工作

6.4 偏波隔离挑战

二偏波MIMO需要保证V-pol和H-pol之间的隔离度>20dB：

  • 偏波正交性好，无需额外频率/时隙资源
  • 亚太赫兹波长短（2mm），可在小面积内实现足够间距

关键判断

  • CMOS工艺是亚太赫兹量产唯一可行路径：成本低、面积小、功耗低、兼容数字电路SoC集成潜力大
  • 65nm CMOS在150GHz已实现实用性能：28nm/12nm节点将进一步突破频率上限
  • 从8单元向16/32单元扩展是必然趋势：更高增益、更远距离

9.1 短期趋势（1-2年）

  • 单元数扩展：从8单元向16/32单元演进，提升阵列增益
  • 工艺升级：28nm/12nm节点应用，进一步提升频率上限和集成度
  • 标准启动：3GPP Rel-21可能启动亚太赫兹标准研究

9.2 中期趋势（2-5年）

  • 波束赋形演进：从全模拟向混合架构演进，提升灵活性和精度
  • AI辅助波束跟踪：AI辅助实时波束跟踪将成为标配
  • 商用原型：2027-2028年迎来首批商用原型产品

9.3 长期趋势（5年以上）

  • 频段拓展：从150GHz向200GHz、300GHz演进
  • 通感一体化：与雷达感知功能融合，实现通信感知一体化
  • 终端普及：从基站回传扩展到终端直连应用

与老大的关联

  • AiP封装技术对中兴终端芯片设计有直接借鉴意义
