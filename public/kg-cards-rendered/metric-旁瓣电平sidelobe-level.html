旁瓣电平Sidelobe-Level

旁瓣电平是主瓣之外最大辐射方向的功率与主瓣最大功率之比——它衡量天线的"干净程度"，旁瓣越低，天线指向越纯粹，抗干扰能力越强。

1.1 旁瓣电平（SLL）

SLL = 20·log₁₀(E_max_sidelobe / E_mainlobe) [dB]
SLL = 10·log₁₀(P_max_sidelobe / P_mainlobe) [dB]

注意：SLL 是负值（旁瓣功率低于主瓣），但工程上常说"SLL = -20dB"表示旁瓣比主瓣低 20dB。

1.2 栅瓣（Grating Lobe）

栅瓣 = 由于单元间距过大而产生的等大旁瓣

当 d > λ/2 时（相控阵），会出现栅瓣——它与主瓣功率几乎相等，是严重的旁瓣问题。

栅瓣条件：
sin(θ_grating) = sin(θ₀) ± n·λ/d

当 d > λ 时，即使 θ₀ = 0° 也有栅瓣（n=1）

1.3 方向图结构

         主瓣
        ╱    ╲
       ╱      ╲    旁瓣
      ╱   ★    ╲  ╱
─────╱──────────╲╱──────

★ = 主瓣峰值
旁瓣 = 主瓣外的次级辐射
栅瓣 = 与主瓣等大的旁瓣（d > λ 时出现）

2.1 SLL 与口径照明分布的关系

均匀照射：SLL = 0dB（最差，第一旁瓣与主瓣等高）
三角形照射：SLL = -23dB
二次方（Cos²）照射：SLL = -32dB
切比雪夫照射：SLL = -20 到 -40dB（可调）
泰勒照射：SLL = -20 到 -30dB（可调）

2.2 均匀照射的旁瓣电平

N 元均匀线阵：
SLL ≈ -13.5dB（恒定，与 N 无关）
第一旁瓣在主瓣两侧 ±λ/(Nd) 处

2.3 切比雪夫阵列的 SLL 设计

给定 SLL 目标值（如 -20dB）：
  设计参数 R = 10^(SLL_dB/20)⁻¹
  R = 10^(-20/20)⁻¹ = 10

切比雪夫多项式系数由 R 决定

典型设计： | SLL 目标 | R 值 | 增益损失 | 备注 | |---------|------|---------|------| | -10dB | 3.16 | 0.1dB | 低隔离 | | -20dB | 10 | 0.3dB | 通用 | | -30dB | 31.6 | 0.8dB | 高隔离 | | -40dB | 100 | 1.5dB | 极端隔离 |

2.4 旁瓣与主瓣宽度的关系

SLL 越低 → 波束越宽（口径效率越低）
SLL 越高 → 波束越窄（口径效率越高）

Trade-off 曲线： | SLL (dB) | 波束展宽因子 | 口径效率损失 | |----------|------------|------------| | 0（均匀） | 1.0× | 0% | | -10 | 1.1× | 5% | | -20 | 1.2× | 10% | | -30 | 1.4× | 18% | | -40 | 1.6× | 25% |

3.2 5G AAU 旁瓣要求

场景 SLL 要求 原因
城市宏站 < -15dB 邻小区干扰控制
密集城区 < -20dB 高密度部署
毫米波基站 < -18dB 波束窄，旁瓣影响大
卫星通信 < -30dB 抗干扰要求高

4.1 暗室测量

设备：暗室 + 转台 + 标准增益天线 + VNA
方法：
  1. 旋转被测天线 360°
  2. 记录每个角度的功率
  3. 找到主瓣峰值和最大旁瓣
  4. SLL = 20·log₁₀(P_sidelobe / P_mainlobe)
精度：±1dB

4.2 OTA 测量

设备：暗室 + 多探头阵列
方法：
  1. 被测天线放在暗室中央
  2. 多探头同时采集方向图
  3. 提取 SLL
优势：适合终端天线（手机、AiP 模组）

4.3 近场扫描

设备：近场扫描系统
方法：
  1. 二维扫描（平面/圆柱/球形）
  2. FFT 变换到远场
  3. 计算 SLL
优势：精度高（±0.5dB），速度快

6.1 栅瓣的避免

相控阵最大扫描角 θ_max：
d/λ ≤ 1 / (1 + |sin(θ_max)|)

θ_max = 0° → d ≤ λ/2
θ_max = 30° → d ≤ 0.67λ
θ_max = 60° → d ≤ 0.5λ
θ_max = 90° → d ≤ 0.5λ

经验法则：相控阵单元间距 d ≤ λ/2 以避免栅瓣。

6.2 旁瓣对系统性能的影响

干扰抑制比 SIR = -SLL

SLL = -20dB → SIR = 20dB
SLL = -10dB → SIR = 10dB

5G 基站旁瓣影响：

  • 旁瓣过高 → 邻小区干扰 ↑ → 系统容量 ↓
  • 旁瓣过高 → 定位精度 ↓（雷达）
  • 旁瓣过高 → 被敌方测向定位 ↑（军用雷达）

6.3 旁瓣抑制技术

技术 效果 代价
口径照明 taper SLL ↓ 5-10dB 增益 ↓ 1-3dB
切比雪夫分布 SLL 可调（-20~-40dB） 复杂度 ↑
泰勒分布 SLL 可调 + 波束窄 复杂度 ↑↑
单元振幅加权 SLL ↓ 3-5dB 馈电网络复杂
单元位置扰动 SLL ↓ 3-8dB 设计复杂
吸收材料 环境旁瓣 ↓ 重量 ↑

6.4 实际系统中的旁瓣恶化

理想 SLL：-20dB
实际 SLL：-15dB（恶化 5dB）

原因：
  1. 单元间距误差（加工公差）
  2. 相位误差（移相器精度）
  3. 幅度误差（馈电网络不一致）
  4. 互耦效应
  5. 安装环境反射
