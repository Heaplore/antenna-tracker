格拉斯哥EMI感知RIS框架

主题概述

RIS有个致命缺陷：来者不拒。

传统RIS像一个"傻镜子"——任何打到它表面的电磁波都会被反射，不管是有用信号还是干扰噪声。在日益拥挤的电磁环境中，这导致RIS不仅放大了目标信号，也放大了电磁干扰（EMI），反而降低了通信质量和定位精度。

格拉斯哥大学James Watt工程学院Saber Hassouna等人提出了一种EMI感知RIS框架（EMI-aware RIS Framework），核心思路不是"抵消"干扰，而是"识别并绕过"干扰。这项研究于2026年发表，并搭建了64×64（4096单元）的真实USRP实验平台在3.5GHz频段验证。

为什么重要： 这是首个同时解决"通信+定位+安全"三大问题的RIS干扰管理方案，而且不需要基站做大量数字信号处理，计算开销极低。

问题建模：空间相关干扰

传统方法假设干扰是白噪声（各向同性、均匀分布），但实际环境中的EMI具有空间相关性——干扰源来自特定方向，具有独特的统计特征。论文建立了包含空间相关干扰的RIS信道模型，量化了干扰对以下指标的影响：

  • 可达数据速率（Achievable Data Rate）
  • 位置误差界（Position Error Bound, PEB）
  • 定位均方根误差（Localization RMSE）

EMI指纹识别（Fingerprinting）

核心创新：分析干扰的二阶空间统计特性。

每个干扰源都有独特的"统计指纹"——类似于每个人的声纹。通过观测接收信号的协方差矩阵，可以提取干扰的空间功率谱分布，从而识别出干扰来自哪些方向、强度如何。

具体做法：

  1. 在RIS相位配置已知的情况下，采集一段时间内的接收信号
  2. 计算信号的自相关矩阵（二阶统计量）
  3. 通过特征分解或子空间分析，分离出信号子空间和干扰子空间
  4. 得到干扰的方向-强度分布（即"指纹"）

几何探测+迭代优化算法

获得干扰指纹后，算法分两步确定最优RIS相位配置：

第一步：粗搜索（Coarse Search） - 在一个小的几何探测方向集合上扫描 - 找到信号最强且干扰最弱的方向组合 - 这一步计算量很小，因为搜索空间被限制在少量候选方向

第二步：精细迭代（Iterative Refinement） - 基于粗搜索结果，使用低复杂度的梯度类算法逐步优化RIS相位 - 每次更新只调整少量单元相位，避免全排列搜索的指数级复杂度 - 收敛到接近最优的相位配置

关键优势： 不需要知道用户的确切位置信息（no explicit user location required），仅依赖干扰的统计特征和信号强度反馈。

与"干扰抵消"方案的本质区别

维度 传统干扰抵消 EMI感知过滤（本文）
思路 基站端数字处理消除干扰 RIS端物理层引导信号绕开干扰
代价 有用信号也被削弱 有用信号保持强度

6G ISAC（Integrated Sensing and Communication）

格拉斯哥大学在2026年2月成立了ISAC³中心（Integrated Sensing, Communication and Computing for Cognitive Cities），这个EMI感知RIS框架正是为ISAC系统量身定制的：

  • 通信方面： 提升可达速率和 secrecy rate（保密速率）
  • 感知方面： 提高定位精度（PEB和RMSE双优化）
  • 安全方面： 天然具备物理层安全能力

实验室验证结果

团队搭建了真实测试床：

  • 频率： 3.5 GHz（与现有5G频段一致，工程落地门槛低）
  • RIS规模： 64×64 = 4096个可编程单元
  • 设备： USRP软件无线电
  • 场景： 5个用户（3个室内可信用户 + 2个走廊潜在窃听者）
  • 结果： RIS成功将波束聚焦到3个可信用户，走廊窃听者完全收不到可用信号

与 TIMES 项目的关联

同一团队还参与了欧洲6G-SNS项目TIMES，研究子太赫兹频段的RIS非视距（NLoS）传输。EMI感知框架可以无缝叠加到时赫兹RIS系统上，为6G室内高速场景（智能工厂、高级研究设施）提供干扰鲁棒性。

格拉斯哥大学的RIS研究矩阵

这个团队在RIS领域已经形成体系化布局：

  1. RISCS（2026早期）： RIS辅助ISAC的网络物理安全框架 — 分类攻击向量（干扰、欺骗、窃听、数据注入），搭建OFDM测试床验证异常检测
  2. EMI感知RIS（2026中期）： 本笔记主题 — 解决干扰过滤问题
  3. TIMES项目（欧洲6G-SNS资助）： 子太赫兹RIS NLoS传输

RIS正从"能不能用"走向"好不好用"

早期RIS研究集中在证明概念可行性（能反射、能转向、能增强信号）。现在进入第二阶段：如何让RIS在真实电磁环境中可靠工作。EMI感知就是第二阶段的标志性突破——它承认现实世界充满干扰，不再假设理想传播环境。

"感知先于控制"是RIS算法的新范式

传统RIS控制算法假设已知信道状态信息（CSI），然后优化相位。EMI感知框架反其道而行：先感知干扰环境（指纹识别），再据此做控制决策。这种"先感知后控制"的范式可以推广到其他RIS应用场景，比如多用户调度、移动性管理、能量收集等。

物理层安全将成为RIS的核心卖点之一

格拉斯哥团队的实验展示了RIS的天然安全能力——定向波束可以让可信用户收到信号，而走廊里的窃听者一无所获。随着6G对隐私和安全的要求越来越高，这种不需要额外加密硬件的物理层安全能力可能成为运营商选择RIS部署的重要驱动力。

直接参考价值

  1. 有源RIS的工程化挑战： 老大关注的有源RIS方向，白皮书里提到了但还没到商用时间表。这个EMI感知框架提供了有源RIS在干扰环境下的实用化路径——不需要在RIS单元上加放大器，纯靠算法就能显著提升性能。

  2. 质量控制的新维度： 作为天线质量岗，传统质检关注的是天线的增益、驻波比、方向图等物理参数。但EMI感知RIS引入了"干扰鲁棒性"这一新的性能维度——RIS在不同干扰场景下的表现如何？这需要新的测试方法和验收标准。

  3. 中兴通讯的RIS布局： IMT-2030的RIS报告里，国内产业链（含中兴）已形成合力。EMI感知算法可以作为中兴RIS系统的软件升级选项，不需要改动硬件即可提升现网性能。

间接启发

  • RIS部署策略： 格拉斯哥的实验表明，RIS单元数量越多（4096单元），干扰过滤效果越好。这意味着大规模RIS部署的边际收益在增加，而不是递减。

  • 频段选择： 实验在3.5GHz完成，这个频段与现有5G频段一致，工程落地门槛低。
