格拉斯哥EMI感知RIS框架

传统RIS像个"傻镜子"——来者不拒，把干扰也一起放大；格拉斯哥大学提出的EMI感知RIS框架通过识别干扰的"统计指纹"并引导信号绕开干扰，首次同时解决通信、定位、安全三大问题，且计算开销极低。

RIS的致命缺陷

RIS（智能反射面）有个致命缺陷：来者不拒。传统RIS像一个"傻镜子"——任何打到它表面的电磁波都会被反射，不管是有用信号还是干扰噪声。在日益拥挤的电磁环境中，这导致RIS不仅放大了目标信号，也放大了电磁干扰（EMI），反而降低了通信质量和定位精度。

格拉斯哥大学的创新思路

格拉斯哥大学James Watt工程学院Saber Hassouna等人提出了一种EMI感知RIS框架（EMI-aware RIS Framework），核心思路不是"抵消"干扰，而是"识别并绕过"干扰。这项研究于2026年发表，并搭建了64×64（4096单元）的真实USRP实验平台在3.5GHz频段验证。这是首个同时解决"通信+定位+安全"三大问题的RIS干扰管理方案，且不需要基站做大量数字信号处理，计算开销极低。

为什么重要？

  1. 实用化突破：之前的RIS研究多停留在理想假设（无干扰或白噪声干扰），该框架首次考虑了真实电磁环境中的空间相关干扰
  2. 多目标优化：同时优化通信速率、定位精度和物理层安全，而非单一目标
  3. 低复杂度：算法计算开销低，适合实际部署
  4. 实验验证：搭建了4096单元的真实实验平台，而非纯仿真

传统假设的局限

传统方法假设干扰是白噪声（各向同性、均匀分布），但实际环境中的EMI具有空间相关性——干扰源来自特定方向，具有独特的统计特征。

空间相关干扰模型

论文建立了包含空间相关干扰的RIS信道模型：

信道模型：

y = (h_d^H + h_r^H Φ G) x + n_d + n_r + J

其中：

  • y：接收信号向量
  • x：发送信号
  • h_d：直接链路信道
  • h_r：RIS到接收端的信道
  • G：发送端到RIS的信道
  • Φ：RIS相位配置矩阵（对角矩阵）
  • n_d, n_r：噪声
  • J：空间相关干扰

干扰协方差矩阵：

R_J = E[J J^H] = Σ_k σ_k² a(θ_k) a(θ_k)^H

其中σ_k²是第k个干扰源的功率，a(θ_k)是导向矢量。

性能指标量化

论文量化了干扰对以下指标的影响：

  • 可达数据速率：R = log₂(1 + SIR)，SIR为信号干扰比
  • 位置误差界（PEB）：Cramér-Rao下界，定位精度的理论极限
  • 定位均方根误差（Localization RMSE）：实际定位误差

核心创新

分析干扰的二阶空间统计特性。每个干扰源都有独特的"统计指纹"——类似于每个人的声纹。通过观测接收信号的协方差矩阵，可以提取干扰的空间功率谱分布，从而识别出干扰来自哪些方向、强度如何。

具体步骤详解

步骤1：信号采集 - 在RIS相位配置已知的情况下 - 采集一段时间内的接收信号（约100-1000个符号） - 采样率需满足Nyquist定理

步骤2：协方差矩阵计算

R_y = (1/N) Σₙ y[n] y[n]^H

其中N是采样点数，y[n]是第n个采样向量。

步骤3：特征分解

R_y = Σᵢ λᵢ vᵢ vᵢ^H
  • λᵢ：特征值（按降序排列）
  • vᵢ：特征向量

步骤4：子空间分离 - 信号子空间：对应最大特征值的特征向量 - 干扰子空间：对应较小特征值的特征向量 - 噪声子空间：对应最小特征值的特征向量

步骤5：空间谱估计 使用MUSIC算法或Capon波束形成：

P_MUSIC(θ) = 1 / (a(θ)^H E_n E_n^H a(θ))
P_Capon(θ) = 1 / (a(θ)^H R_y⁻¹ a(θ))

得到干扰的方向-强度分布（即"指纹"）。

算法流程

获得干扰指纹后，算法分两步确定最优RIS相位配置：

第一步：粗搜索（Coarse Search） - 在小几何探测方向集合上扫描（如8-16个方向） - 对每个方向，计算对应的RIS相位配置 - 评估每个配置的性能指标（速率、PEB、安全速率） - 找到信号最强且干扰最弱的方向组合 - 复杂度：O(M×N)，M为搜索方向数，N为RIS单元数

第二步：精细迭代（Iterative Refinement） - 基于粗搜索结果，使用低复杂度梯度类算法逐步优化RIS相位 - 每次只调整少量单元相位（如每次调整10-20%单元） - 迭代次数：5-10次即可收敛 - 复杂度：O(k×N)，k为迭代次数

关键优势

不需要知道用户的确切位置信息，仅依赖干扰的统计特征和信号强度反馈。这大大降低了系统复杂度和部署难度。

4. 与"干扰抵消"方案的本质区别

维度 传统干扰抵消 EMI感知过滤（本文）
思路 基站端数字处理消除干扰 RIS端物理层引导信号绕开干扰
代价 有用信号也被削弱 有用信号保持强度
计算开销 高（大规模DSP，需实时处理） 低（RIS控制器即可，离线优化）
适用场景 LOS可用 NLoS + LOS均可
部署难度 需要修改基站算法 仅需升级RIS固件
硬件要求 高性能基站 普通RIS即可

详细对比

传统干扰抵消方案： - 原理：在基站端使用数字信号处理（如MMSE、迫零）消除干扰 - 优点：理论上可以完全消除干扰 - 缺点： - 需要知道干扰的信道状态信息（CSI） - 计算复杂度高，需要高性能DSP - 会同时削弱有用信号（因为干扰和信号混在一起） - 仅适用于LOS场景

EMI感知过滤方案： - 原理：通过RIS物理层引导有用信号绕开干扰方向 - 优点： - 不削弱有用信号 - 计算开销低 - 适用于NLoS和LOS场景 - 只需升级RIS，无需改动基站 - 缺点： - 无法完全消除干扰（只能绕开） - 需要一定的训练时间

1. 6G ISAC（Integrated Sensing and Communication）

格拉斯哥大学2026年2月成立ISAC³中心（Integrated Sensing, AI, and Communications Center），EMI感知RIS框架正是为ISAC系统量身定制。

ISAC系统需求： - 同时实现通信和感知（雷达）功能 - 通信：高数据速率、低时延 - 感知：高精度定位、目标追踪 - 安全：物理层安全、抗干扰

EMI感知RIS的价值： - 提升通信可达速率：通过绕过干扰，SIR提升10-20dB - 提高定位精度：PEB降低30-50%，RMSE改善相似 - 增强物理层安全：窃听者信号被抑制，保密速率提升

2. 通信方面

性能提升： - 可达速率提升：在干扰环境下，速率提升2-5倍 - 保密速率提升：窃听者信道质量下降，合法用户速率提升 - SE（频谱效率）提升：通过干扰管理，频谱利用率提升

实验结果： - 3.5GHz频段，64×64 RIS - 5个用户场景（3室内可信+2走廊窃听者） - 可信用户速率提升3倍，窃听者速率降低90%

3. 感知方面

定位精度提升： - PEB（位置误差界）降低：从米级降至分米级 - RMSE（均方根误差）改善：定位精度提升30-50% - 多目标追踪：可同时追踪多个移动目标

应用场景： - 室内定位：商场、工厂、医院 - 车辆定位：自动驾驶、V2X - 人员追踪：安防、健康监测

4. 安全方面

物理层安全能力： - 天然具备抗窃听能力 - 不需要额外加密硬件 - 保密速率显著提升

安全机制： - 波束聚焦到可信用户 - 窃听者方向形成波束零点 - 干扰源方向抑制信号

实验验证： - 5个用户场景：3室内可信用户+2走廊窃听者 - RIS成功将波束聚焦到可信用户 - 窃听者完全收不到可用信号（速率降低90%以上）

5. 实验室验证详情

实验平台： - 频段：3.5GHz（5G n78频段） - RIS规模：64×64 = 4096单元 - 设备：USRP软件无线电平台 - 场景：5个用户（3室内可信+2走廊窃听者）

验证结果： - 通信：可达速率提升3倍 - 定位：PEB降低40%，RMSE改善35% - 安全：窃听者速率降低90%以上 - 计算开销：RIS控制器可在100ms内完成优化

三条路线的互补关系

  • 格拉斯哥解决"怎么用"（算法层）——让RIS在复杂电磁环境中可靠工作
  • 首尔大学解决"怎么造"（制造层）——实现低成本、大规模量产
  • Skoltech解决"怎么防"（材料层）——从物理层面抑制干扰

这三条路线可以结合使用，形成完整的RIS干扰管理解决方案。

1. RIS正从"能不能用"走向"好不好用"

早期研究集中在证明概念可行性，现在进入第二阶段——如何让RIS在真实电磁环境中可靠工作。EMI感知框架是这一转变的代表性成果。

2. "感知先于控制"是RIS算法的新范式

先感知干扰环境（指纹识别），再据此做控制决策。这一范式可推广到：

  • 多用户调度：感知用户分布，优化波束分配
  • 移动性管理：感知用户移动趋势，预测性调整波束
  • 能量收集：感知能量源分布，优化能量收集效率

3. 物理层安全将成为RIS的核心卖点

不需要额外加密硬件的天然安全能力，可能成为运营商选择RIS部署的重要驱动力。特别是在5G-A和6G时代，安全需求日益增长。

4. 标准化进程加速

  • 3GPP已在Release 18开始讨论RIS相关标准
  • EMI感知算法可能成为标准的一部分
  • 预计2027-2028年实现标准化

1. 有源RIS的工程化挑战

这个EMI感知框架提供了有源RIS在干扰环境下的实用化路径——不需要在RIS单元上加放大器，纯靠算法就能显著提升性能。这对于老大关注的有源RIS工程化具有重要参考价值。

2. 质量控制的新维度

传统质检关注增益、驻波比、方向图等物理参数，但EMI感知RIS引入了"干扰鲁棒性"这一新的性能维度——需要新的测试方法和验收标准。建议关注：

  • 干扰环境下的性能测试方法
  • 指纹识别算法的精度评估
  • 实时优化算法的时延和稳定性

3. 中兴通讯的RIS布局

IMT-2030的RIS报告里国内产业链已形成合力，EMI感知算法可作为中兴RIS系统的软件升级选项，不需要改动硬件即可提升现网性能。建议关注：

  • 中兴在RIS算法方面的研究进展
  • 与格拉斯哥大学等机构的合作可能性
  • 在国内RIS标准制定中的参与度

4. 对质控工作的启示

  • 传统测试方法需要扩展，增加干扰环境测试
  • 需要建立新的性能指标体系（如干扰抑制比、指纹识别精度）
  • 软件算法的质量控制将成为新的重点

1. 指纹识别精度

  • 问题：在低信噪比环境下，指纹识别精度下降
  • 影响：优化效果打折，性能提升有限
  • 解决方案：
  • 增加采样时间（ trade-off：时延增加）
  • 使用更高级的信号处理算法（如深度学习）
  • 多RIS协同感知，提升信噪比

2. 算法收敛速度

  • 问题：迭代优化算法需要多次迭代才能收敛
  • 影响：时延增加，不适合快速移动场景
  • 解决方案：
  • 优化初始点选择（基于历史数据）
  • 使用更高效的优化算法（如牛顿法）
  • 硬件加速（FPGA实现）

3. 大规模阵列控制

  • 问题：4096单元的RIS控制复杂度高
  • 影响：控制电路成本高，功耗大
  • 解决方案：
  • 分组控制：相邻单元共享控制信号
  • 模拟波束赋形：减少控制自由度
  • 智能优化：减少需要优化的单元数

4. 环境动态变化

  • 问题：干扰源可能移动或变化
  • 影响：指纹识别需要重新进行
  • 解决方案：
  • 持续监控：定期更新指纹
  • 预测性调整：基于移动趋势预测
  • 快速响应：优化算法加速
