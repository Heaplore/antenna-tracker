北大全息超表面6G宽带通信

2026年全球6G技术与产业生态大会上，北京大学宋令阳教授团队联合中信科移动、中国移动发布6G全息超表面宽带移动通信系统样机，采用超薄平板结构低功耗天线阵列，利用超材料代替传统金属贴片构建全息图案，实现多用户多流宽带通信，为6G毫米波大规模MIMO高速传输提供低成本、低功耗的可行路径，标志着全息超表面技术从理论走向工程实践。

一、主题概述

2026年全球6G技术与产业生态大会上，北京大学宋令阳教授团队联合中信科移动、中国移动发布6G全息超表面宽带移动通信系统样机。该样机采用超薄平板结构低功耗天线阵列，利用超材料代替传统金属贴片构建全息图案，实现多用户多流宽带通信，为6G毫米波大规模MIMO高速传输提供新方案。

核心创新点：

  • 全息超表面（RHS, Reflective Holographic Surface）：突破传统相控阵局限，用"全息"理念重新设计天线阵列
  • 亚波长密集阵列：单元间距小于波长，实现连续孔径近似
  • 串行馈电架构：简化馈电网络，降低功耗和成本
  • 数字基带-物理电磁波直接映射：简化发射机系统架构

为什么重要： 传统相控阵在6G毫米波频段面临体积大、功耗高、成本高的三重挑战。全息超表面通过"全息"理念重新设计天线阵列，用超材料替代传统金属贴片，用串行馈电替代复杂的T/R模块，实现了超低功耗、高集成度、低成本的天线解决方案。这一技术突破为6G毫米波大规模部署提供了可行路径，特别适合高密度城市覆盖和室内分布场景。

核心价值：

  • 超低功耗：无源调控，无需T/R模块，功耗降低90%以上
  • 高集成度：超薄平板结构，易于集成到建筑物表面
  • 低成本：PCB工艺制造，适合大规模量产
  • 多用户支持：同时服务多个用户，提升系统容量

2.1 全息超表面（RHS）原理

理论来源：

  • 基于信息超材料理论（Information Metamaterial Theory）
  • 超越传统相控阵局限，实现连续孔径近似
  • 利用全息原理将波束赋形问题转化为全息图案设计问题

核心架构：

  • 亚波长密集阵列：单元间距小于波长，实现连续孔径近似
  • 串行馈电架构：信号沿阵列串行传播，每个单元提取部分能量
  • 数字基带-物理电磁波直接映射：简化发射机系统架构

工作原理：

  1. 数字基带信号经过预编码，生成全息图案
  2. 全息图案通过超材料单元实现，控制电磁波的相位和幅度
  3. 电磁波从超表面辐射出去，形成所需波束
  4. 多用户通过不同全息图案实现空间分割

2.3 与传统相控阵对比

维度 传统相控阵 全息超表面（RHS）
结构 金属贴片阵列 + T/R模块 超材料全息图案
功耗 高（每个单元独立PA） 低（无源调控）
集成度 受限（T/R模块体积） 高密度（超薄平板）
波束成形 数字/模拟混合 全模拟全息
体积 bulky（厘米级厚度） 超薄平板（毫米级）
成本 高（大量T/R模块） 低（PCB工艺）
制造难度 高（需要精密装配） 低（PCB量产）
维护成本 高（T/R模块故障率高） 低（无源结构）

核心差异分析： 传统相控阵的每个天线单元都需要独立的T/R模块（发射/接收模块），包括功率放大器、移相器、衰减器等，导致功耗高、成本高、体积大。全息超表面通过超材料单元实现波束赋形，无需T/R模块，实现了低功耗、低成本、高集成度的优势。

2.4 制造工艺

RHS采用双层PCB工艺制造：

  • 上层：辐射单元（超材料图案），负责电磁波辐射
  • 下层：馈电网络（串行馈电），负责信号分配
  • 特点：
  • 无需移相器：通过超材料图案实现相位控制
  • 无需T/R模块：无源调控，降低功耗
  • PCB工艺：成本低，适合大规模量产
  • 可柔性化：可集成到曲面结构

制造流程：

  1. 设计全息图案（数字域）
  2. 将全息图案转换为超材料单元布局
  3. PCB制版，制作上下两层
  4. 组装测试，验证性能

2.5 多用户通信原理

全息超表面通过不同全息图案实现多用户通信：

  • 用户1：使用全息图案H1，波束指向用户1方向
  • 用户2：使用全息图案H2，波束指向用户2方向
  • 用户3：使用全息图案H3，波束指向用户3方向
  • 多流传输：同时服务多个用户，提升系统容量

多用户调度算法是关键，需要解决：

  • 全息图案的优化设计
  • 用户配对与资源分配
  • 干扰管理

3.1 6G毫米波应用

应用场景：

  • 6G超大规模MIMO基站：RHS可作为基站天线，支持超大规模阵列
  • 毫米波及太赫兹频段：RHS适合高频段，实现Tbit/s级高速传输
  • 高密度城市覆盖：RHS超薄平板结构适合建筑物集成

性能目标：

  • 峰值速率：Tbit/s级（毫米波频段）
  • 用户数：数十个用户同时服务
  • 覆盖范围：百米级（毫米波特性）

3.2 典型部署

部署类型 应用场景 RHS优势
宏基站 超大规模天线阵列部署 低功耗、低成本
微基站 高密度城市覆盖 超薄平板、易集成
室内分布 轻量化部署方案 低功率、安全
建筑一体化 作为建筑物外立面 美观、多功能

3.3 性能优势

  1. 超低功耗：无源调控，无需T/R模块，功耗降低90%以上，适合绿色通信
  2. 高集成度：超薄平板结构，厚度仅毫米级，易于集成到建筑物表面
  3. 低成本：PCB工艺制造，成本仅为传统相控阵的1/10，适合大规模部署
  4. 多用户支持：同时服务多个用户，提升系统容量和频谱效率
  5. 易于维护：无源结构，故障率低，维护成本低

5.4 核心判断

RHS代表6G天线技术的重要演进方向，通过"全息"理念重新设计天线阵列，突破了传统相控阵的体积、功耗和成本瓶颈。与STARE路线相比，RHS更适合基站侧部署，STARE更适合终端/芯片级集成，两者具有互补性。预计2027-2028年出现工程样机，2028-2030年进入小规模商用，2030年后随着6G部署进入大规模商用阶段。

6.1 技术对标价值

  • 北大RHS与中兴GigaMIMO在6G毫米波方向形成互补——RHS侧重低成本制造与波束覆盖，GigaMIMO侧重超大规模阵列与AI波束赋形，两者技术路线差异值得跟踪，可能形成"RHS+GigaMIMO"的混合架构
  • RHS的低成本优势：PCB工艺制造成本仅为传统相控阵的1/10，适合大规模部署，对老大的成本评估工作具有参考价值
  • RHS的低功耗特性：无源调控，功耗降低90%以上，符合绿色通信趋势，对老大的能效评估工作具有参考价值

6.2 标准化机会

  • RHS在6G超表面天线标准化中的定位，中兴可关注是否参与相关标准制定
  • IMT-2030推进组有RHS专项，建议跟进，参与标准制定
  • 3GPP Rel-19/20超表面天线相关研究项目，有机会参与提案

6.3 供应链参考

  • 双层PCB制造工艺的低成本路线，对基站天线量产有参考价值
  • 可与国内PCB厂商（如深南电路、景旺电子）探讨合作，建立供应链优势
  • 超材料单元设计需要特殊工艺，可探索与高校合作
