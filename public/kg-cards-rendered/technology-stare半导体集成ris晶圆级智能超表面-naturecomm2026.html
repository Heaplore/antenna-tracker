STARE半导体集成RIS晶圆级智能超表面-NatureComm2026

首尔大学团队在Nature Communications发表的世界首个采用标准半导体工艺制造的RIS系统——STARE（Semiconductor Transmit Array with Reconfigurable Elements），采用高阻硅基底+定制SOD二极管，实现180°相移控制和±45°波束扫描，15.5GHz验证，为6G智能超表面大规模量产铺平道路。

主题概述

STARE（Semiconductor Transmit Array with Reconfigurable Elements）是首个采用标准半导体工艺制造的RIS系统，发表在Nature Communications 2026。该设计采用高阻硅基底+定制Selective Overlap Diode（SOD）二极管，实现180°相移控制和±45°波束扫描，工作频率15.5GHz。核心突破在于将RIS单元与CMOS工艺兼容，为大规模量产奠定基础。

核心价值：首次证明RIS可以用半导体代工厂的标准工艺制造，从"手工定制"走向"晶圆级量产"，成本有望降至传统方案的1/10。

1.1 技术背景

RIS（Reconfigurable Intelligent Surface，智能反射面）是6G核心使能技术之一：

  • 由大量低成本无源反射单元组成
  • 每个单元可独立控制电磁波的相位、幅度、极化
  • 通过软件定义无线传播环境，实现"智能反射"

当前RIS的技术瓶颈： | 瓶颈 | 传统方案问题 | |------|-------------| | 离散元件方案 | 基于PIN二极管、变容二极管或MEMS，体积大、功耗高、一致性差 | | 液晶方案 | 响应慢（毫秒级）、温度敏感、功率容量低 | | 半导体方案缺失 | 缺乏与CMOS工艺兼容的RIS实现路径 |

STARE的突破：首次采用标准半导体工艺制造RIS系统，bridging device-level fabrication与system-level beamforming。

1.2 核心创新：STARE架构

STARE = Semiconductor Transmit Array with Reconfigurable Elements

核心设计：

  1. Selective Overlap Diode (SOD)：定制设计的重叠二极管，实现可调ON电阻和OFF电容
  2. Vialess transmit-type unit cell：无过孔透射型单元，采用磁耦合而非传统垂直互连
  3. 高阻硅基底：降低衬底损耗，提升Q值

工作原理流程图：

入射电磁波 → RIS单元阵列 → 相位调控 → 反射/透射波前整形 → 目标方向波束
                ↑
           DC偏置电压（控制二极管状态）

每个STARE单元：

  • 包含一个SOD二极管和辐射单元
  • 通过改变偏置电压，调节二极管的导通状态
  • 导通状态改变单元的等效阻抗，从而改变反射相位
  • 180°相移范围覆盖波束扫描需求

1.3 Selective Overlap Diode (SOD)

SOD是STARE的核心创新：

参数 传统PIN二极管 SOD二极管
ON电阻 固定 可调
OFF电容 固定 可调
尺寸 较大 紧凑
工艺兼容性 低 高

SOD设计要点：

  1. 自定义掺杂分布，优化载流子注入效率
  2. 重叠电极结构，减小串联电阻
  3. 与CMOS工艺兼容，支持晶圆级制造

1.4 Vialess透射型单元设计

传统RIS单元问题：

  • 需要TSV（硅通孔）实现垂直互连
  • TSV工艺复杂、成本高、引入寄生参数

STARE解决方案：

  • 磁耦合替代电耦合
  • 单元间通过近场磁耦合传递能量
  • 无需TSV，简化制造工艺
  • 降低衬底损耗

1.5 单元细胞设计

单层STARE单元结构：

  1. 辐射单元：偶极子或微带贴片，工作于15.5GHz
  2. SOD二极管：集成在辐射单元中心
  3. 偏置网络：DC馈电，RF接地
  4. 高阻硅基底：ρ > 10kΩ·cm

性能指标： | 指标 | 数值 | |------|------| | 相移范围 | 180°（理想）/ 150°（实测） | | 插入损耗 | ≤ 1.5 dB | | 偏置电压 | 0-5V | | 单元面积 | λ₀/2 × λ₀/2 ≈ 5mm × 5mm @ 15.5GHz |

1.6 阵列设计与波束赋形

4×4 STARE阵列：

  • 总单元数：16个
  • 阵列尺寸：20mm × 20mm
  • 单元间距：λ₀/2（避免栅瓣）

波束赋形算法：

  1. 相位分布计算：根据目标波束方向，计算各单元所需相位
  2. 偏置电压映射：将相位需求转换为二极管偏置电压
  3. 查找表预编程：建立相位-电压映射表，实时查表控制

扫描范围：±45°（俯仰+方位）

4.1 6G基站智能反射面

场景描述：

  • 在基站天线阵列中集成STARE单元
  • 动态调整波束方向，跟踪移动用户
  • 填补覆盖盲区，提升边缘速率

优势：

  1. 半导体工艺，可与基站芯片集成
  2. 低功耗，适合大规模部署
  3. 低成本，适合城市密集部署

4.2 室内智能覆盖

场景描述：

  • 部署在天花板或墙壁
  • 动态调整室内无线覆盖
  • 支持多用户MIMO

优势：

  1. 超薄设计（数毫米）
  2. 美观，可嵌入建筑材料
  3. 即装即用，无需布线

4.3 卫星通信终端

场景描述：

  • 低轨卫星互联网终端
  • 相控阵波束指向卫星
  • 支持高速移动

优势：

  1. 半导体工艺，抗振动
  2. 重量轻，适合星载
  3. 低功耗，适合太阳能供电

4.4 V2X车联网

场景描述：

  • 路侧单元（RSU）集成STARE
  • 动态波束跟踪车辆
  • 提升车联网可靠性和容量

优势：

  1. 快速响应（ns级）
  2. 高可靠性（无机械部件）
  3. 低成本，适合大规模部署

工程挑战与坑

工艺挑战： | 问题 | 解决方案 | |------|---------| | 高阻硅材料获取 | 与半导体代工厂合作，开发专用工艺 | | SOD二极管一致性 | 设计容差分析，增加校准电路 |

热管理：

  • 问题：大规模阵列总功耗不可忽视
  • 解决：优化偏置网络，采用动态功耗管理
  • 问题：二极管参数随温度漂移
  • 解决：温度补偿算法，或选择温度不敏感工作点

校准与测试：

  • 问题：每个单元需单独校准
  • 解决：批量测试方案，自动化校准
  • 问题：长期可靠性未知
  • 解决：加速寿命测试，建立失效模型
