STARE半导体集成RIS晶圆级智能超表面-NatureComm2026

首尔大学团队在Nature Communications发表的世界首个采用标准半导体工艺制造的RIS系统——STARE（Semiconductor Transmit Array with Reconfigurable Elements），采用高阻硅基底+定制SOD二极管，实现180°相移控制和±45°波束扫描，15.5GHz验证，为6G智能超表面大规模量产铺平道路。

1.1 技术背景

RIS（Reconfigurable Intelligent Surface，智能反射面）是6G核心使能技术之一：

  • 由大量低成本无源反射单元组成
  • 每个单元可独立控制电磁波的相位、幅度、极化
  • 通过软件定义无线传播环境，实现"智能反射"

当前RIS的技术瓶颈：

  1. 离散元件方案：基于PIN二极管、变容二极管或MEMS，体积大、功耗高、一致性差
  2. 液晶方案：响应慢（毫秒级）、温度敏感、功率容量低
  3. 半导体方案缺失：缺乏与CMOS工艺兼容的RIS实现路径

STARE的突破：首次采用标准半导体工艺制造RIS系统， bridging device-level fabrication与system-level beamforming。

1.2 核心创新：STARE架构

STARE = Semiconductor Transmit Array with Reconfigurable Elements

核心设计：

  1. Selective Overlap Diode (SOD)：定制设计的重叠二极管，实现可调ON电阻和OFF电容
  2. Vialess transmit-type unit cell：无过孔透射型单元，采用磁耦合而非传统垂直互连
  3. 高阻硅基底：降低衬底损耗，提升Q值

1.3 工作原理

入射电磁波 → RIS单元阵列 → 相位调控 → 反射/透射波前整形 → 目标方向波束
                ↑
           DC偏置电压（控制二极管状态）

每个STARE单元：

  • 包含一个SOD二极管和辐射单元
  • 通过改变偏置电压，调节二极管的导通状态
  • 导通状态改变单元的等效阻抗，从而改变反射相位
  • 180°相移范围覆盖波束扫描需求

2.1 Selective Overlap Diode (SOD)

SOD是STARE的核心创新：

参数 传统PIN二极管 SOD二极管
ON电阻 固定 可调
OFF电容 固定 可调
尺寸 较大 紧凑
工艺兼容性 低 高

SOD设计要点：

  1. 自定义掺杂分布，优化载流子注入效率
  2. 重叠电极结构，减小串联电阻
  3. 与CMOS工艺兼容，支持晶圆级制造

2.2 Vialess透射型单元设计

传统RIS单元问题：

  • 需要TSV（硅通孔）实现垂直互连
  • TSV工艺复杂、成本高、引入寄生参数

STARE解决方案：

  • 磁耦合替代电耦合
  • 单元间通过近场磁耦合传递能量
  • 无需TSV，简化制造工艺
  • 降低衬底损耗

2.3 单元细胞设计

单层STARE单元结构：

  1. 辐射单元：偶极子或微带贴片，工作于15.5GHz
  2. SOD二极管：集成在辐射单元中心
  3. 偏置网络：DC馈电，RF接地
  4. 高阻硅基底：ρ > 10kΩ·cm

性能指标：

  • 相移范围：180°（理想）/ 150°（实测）
  • 插入损耗：≤ 1.5 dB
  • 偏置电压：0-5V
  • 单元面积：λ₀/2 × λ₀/2 ≈ 5mm × 5mm @ 15.5GHz

2.4 阵列设计与波束赋形

4×4 STARE阵列：

  • 总单元数：16个
  • 阵列尺寸：20mm × 20mm
  • 单元间距：λ₀/2（避免栅瓣）

波束赋形算法：

  1. 相位分布计算：根据目标波束方向，计算各单元所需相位
  2. 偏置电压映射：将相位需求转换为二极管偏置电压
  3. 查找表预编程：建立相位-电压映射表，实时查表控制

扫描范围：±45°（俯仰+方位）

3.2 制造工艺

STARE制造流程：

  1. 高阻硅片准备：float-zone硅，ρ > 10kΩ·cm
  2. 光刻定义：形成SOD二极管区域
  3. 离子注入：调整掺杂浓度
  4. 金属化：蒸发/溅射铜或铝
  5. 刻蚀：形成辐射单元和传输线
  6. 封装：陶瓷或有机基板封装

关键工艺参数：

  • 光刻分辨率：≤ 5μm
  • 金属厚度：2-5μm
  • 表面粗糙度：Ra < 0.5μm

3.3 测试与验证

测试平台：

  • 微波暗室
  • 矢量网络分析仪（VNA）
  • 频谱分析仪
  • 直流电源（偏置控制）

关键测试项目：

  1. S参数测量：S11（回波损耗）、S21（插入损耗）
  2. 相位响应测量：不同偏置电压下的反射相位
  3. 波束扫描测量：远场方向图
  4. 功耗测量：静态偏置功耗
  5. 温度稳定性测试：-40°C ~ +85°C

6.1 工艺挑战

高阻硅材料获取：

  • 问题：高阻硅片价格昂贵，尺寸有限
  • 解决：与半导体代工厂合作，开发专用工艺

SOD二极管一致性：

  • 问题：工艺波动导致二极管参数分散
  • 解决：设计容差分析，增加校准电路

6.2 热管理

功耗累积：

  • 问题：大规模阵列总功耗不可忽视
  • 解决：优化偏置网络，采用动态功耗管理

温度稳定性：

  • 问题：二极管参数随温度漂移
  • 解决：温度补偿算法，或选择温度不敏感工作点

6.3 校准与测试

生产测试成本高：

  • 问题：每个单元需单独校准
  • 解决：批量测试方案，自动化校准

长期可靠性验证：

  • 问题：半导体RIS长期稳定性未知
  • 解决：加速寿命测试，建立失效模型

6.4 系统集成

与现有通信系统兼容：

  • 问题：STARE需要与控制基带协同工作
  • 解决：定义标准接口协议，推动标准化

大规模部署成本：

  • 问题：单位面积成本需足够低
  • 解决：晶圆级制造，规模效应
