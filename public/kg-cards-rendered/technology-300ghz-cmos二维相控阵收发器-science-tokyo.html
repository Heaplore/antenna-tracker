300GHz CMOS二维相控阵收发器-Science Tokyo

东京科学大学冈田健一教授团队在2026 IEEE/JSAP VLSI Circuits会议上发表世界首款300 GHz全CMOS二维4×4相控阵收发器IC，将16路双通道收发电路+片上天线集成在同一65nm芯片上，单素子功耗仅26mW、面积0.30mm²，实现±32°双向波束扫描，为6G太赫兹通信低成本量产铺平道路。

1.1 什么是300 GHz CMOS相控阵收发器

300 GHz频段属于太赫兹（Terahertz）带的下限区域（300 GHz–3 THz），是IEEE 802.15.3d标准定义的252–325 GHz频段的核心部分。该频段拥有超大带宽潜力（理论上可达100+ Gbps），但面临两个致命挑战：

  1. 自由空间路径损耗（FSPL）极大：300 GHz的波长λ≈1mm，路径损耗比2.4 GHz高出约40 dB
  2. 集成密度极限：半波长远小于1mm，天线与收发电路难以在同一芯片上紧凑排布

相控阵（Phased Array）通过多个天线单元的相位差控制，实现电子波束扫描，无需机械转动即可将能量定向发射，从而补偿巨大的路径损耗。

本研究的突破性在于：用纯CMOS工艺（而非昂贵的GaAs/GaN化合物半导体）实现了全集成300 GHz二维相控阵收发器，且天线间距达到严格的半波长。

1.2 核心难点：半波长间距集成

300 GHz的波长约1mm，半波长仅约0.5mm。要在如此微小的空间内同时容纳：

  • 天线单元（偶极子+接地屏蔽+背腔）
  • 移相器（控制波束方向）
  • 逓倍器（频率合成）
  • 注入同步式逓倍器（LO生成）
  • 次谐波混频器（RX前端）
  • 射频走线和电源

这相当于在一粒米的空间里塞进一个完整的无线电系统。

1.3 东京科学大学的突破

东京科学大学（Science Tokyo，2024年由东京工业大学和东京医科齿科大学合并）冈田健一教授团队采用65nm CMOS工艺，实现了：

  • 2次元4×4アレイ：16系统的双向收发回路集成在1颗IC上
  • オンチップアンテナ：片上天线，无需外接
  • 半波長間隔：天线单元精确按半波长（E面0.49λ / H面0.50λ）间距排列
  • バックサイド溝加工：基板背面开槽形成半独立腔体，抑制基板损耗

2.2 各素子构成

每单元包含：

  1. 移相器（Phase Shifter）：控制波束扫描角度
  2. 逓倍器（Frequency Multiplier）：将本振频率倍频到300 GHz
  3. 注入同步式逓倍器（Injection-Synchronized Multiplier）：低相位噪声LO源
  4. 次谐波混频器（Sub-Harmonic Mixer）：接收前端，降低LO需求
  5. オンチップ・ダイポールアンテナ（片上天线偶极子）：辐射元件

关键电路架构：

  • 发射端：移相器 → 倍频器 → 注入锁定三倍频器（ILT）
  • 接收端：次谐波混频器（mixer-first架构）
  • 双通道设计：TX/RX共用同一套天线，无需开关切换

2.3 天线创新：背腔结构

┌─────────────────────┐
│   正面（元件层）     │  ← CMOS电路+移相器+逓倍器等
│   [天线辐射体]       │
├─────────────────────┤
│   グラウンドシールド │  ← 隔离相邻素子干扰
├─────────────────────┤
│   基板               │
│   ▽▽▽ 溝加工 ▽▽▽   │  ← 背面开槽形成腔体
├─────────────────────┤
│   半独立キャビティ    │  ← 束缚电磁波，减少基板损耗
└─────────────────────┘
         ↓ 放射方向

背腔结构使天线增益平均提升4 dB，是解决300 GHz基板损耗的关键创新。

三、实现方式与分类

按工艺路线，300 GHz相控阵主要有三条技术路径：

工艺 优势 劣势 代表
CMOS（本成果） 成本低、可大规模量产、易集成控制电路 高频性能有限、输出功率较低 Science Tokyo系列（2021 ISSCC → 2026 VLSI）
GaAs/GaN 高频性能好、输出功率高 成本高、难集成、良率挑战 卫星通信、雷达应用
InP 300 GHz性能最优 极昂贵、与CMOS不兼容、需混合封装 东工大+NTT 2023 IMS混合方案
SiGe BiCMOS 噪声性能优，适合接收端 频率上限低于InP Intel 257 GHz 64Rx/16Tx

为什么坚持CMOS而非化合物半导体：6G要普及，CMOS是唯一可能的量产路径。东京科学大学的突破正是证明了即使CMOS高频性能有限，通过架构创新（2D相控阵+功率合成+高增益天线）也能实现实用通信。

6.1 EIRP -17.1 dBm意味着什么

-17.1 dBm的峰值EIRP看似不高（约0.02 mW等效全向辐射），但考虑到：

  • 300 GHz频段路径损耗极大（自由空间损耗≈40log(d)+20log(f)+92.4≈114 dB@1m）
  • 16素子功率合成后仍能达到此水平
  • 数米范围内通信绰绰有余
  • 对于Femtocell/室内场景完全够用

6.2 26 mW/素子的意义

对比业界同类300 GHz CMOS收发器：

  • 传统方案：每素子100-200 mW
  • 东京科学大学：26 mW（世界最低）
  • 这意味着16素子总功耗仅约400 mW，可以用电池供电，适合终端设备

6.3 为什么半波长间距至关重要

300 GHz波长λ≈1 mm，半波长≈0.5 mm。天线间距如果超过半波长，会出现栅瓣（grating lobe）——波束分裂成多个方向，失去定向性。东京科学大学实现了E面0.49λ、H面0.50λ的严格半波长间距，有效抑制了栅瓣。

7.1 相邻素子干扰

300 GHz波长仅1 mm，16个素子挤在几mm²内，互耦（Mutual Coupling）极其严重。解决方案：

  • グラウンドシールド（接地屏蔽）隔离相邻素子
  • 背腔结构将辐射方向改为基板背面，减少正面互耦

7.2 基板损耗

硅基板在300 GHz的损耗角正切高达0.01-0.1，电磁波在基板内传播损耗极大。解决方案：

  • 背面沟槽加工（grooving）形成半独立腔体
  • 将辐射能量束缚在腔体内，减少基板模式激发

7.3 热管理

虽然单素子仅26 mW，但16素子+控制电路集中在0.3 mm²区域，热密度极高。65 nm CMOS的散热能力有限，大规模集成时需要：

  • 考虑Flip-chip倒装焊到高热导率基板
  • 可能需要集成微型热电冷却器（TEC）

7.4 2D波束扫描的局限性

±32°的扫描范围对于室内Femtocell够用，但如果要覆盖更广角度（如室外宏站），需要：

  • 更大阵列（8×8或16×16）
  • 更多移相器精度
  • 更复杂的波束控制算法

十、趋势判断

  1. CMOS是太赫兹量产的唯一路径：GaN/GaAs性能更好但成本太高，65 nm CMOS在300 GHz已能实现实用性能，28 nm及以下节点将进一步突破频率上限
  2. 从4×4到更大规模是必然：当前4×4只是验证芯片级集成可行性，未来16×16甚至64×64的片上相控阵将成为基站AAU的核心前端
  3. 三维堆叠+片上天线是必由之路：2024年的64单元3D堆叠方案和2026年的片上天线方案表明，传统PCB布线在300 GHz已不可行，必须走向3D IC集成和片上辐射
  4. 与RIS可能融合：东京科学大学的CMOS相控阵+首尔大学的STARE晶圆级RIS，两条路线可能在6G太赫兹系统中融合——相控阵做主波束，RIS做辅助反射面
  5. 台积电28nm/16nm节点有望进一步将频率上限推至400-500 GHz

11.1 GigaMIMO技术栈延伸

老大参与的中兴GigaMIMO项目聚焦亚6G/U6G频段，300 GHz太赫兹是GigaMIMO的自然延伸——从亚6G到UWB再到太赫兹，天线规模从千级向万级演进。中兴在毫米波专利布局上已有深厚积累，300 GHz方向值得提前卡位。

11.2 半导体级天线趋势

这篇笔记是继STARE晶圆级RIS之后的又一半导体级天线突破。老大的天线知识库已覆盖：

  • 系统级：中兴GigaMIMO、华为U6 GHz AAU、MWC26低空通感
  • RIS级：STARE晶圆级RIS、清华SC-RIS、有源ORIS
  • 芯片级：本篇300 GHz CMOS相控阵

三条路线正在收敛——半导体工艺进步让天线从"外挂模块"变成"片上集成"，这对中兴的6G研发方向有直接参考价值。建议后续追踪中兴是否有太赫兹频段的内部预研项目。

11.3 对中兴的启示

中兴目前的Pre6G重心在GigaMIMO（Sub-6G空域重构）和低空通感（毫米波AAU），300 GHz太赫兹属于更后期的技术储备。但CMOS相控阵芯片是终端侧和基站侧的共同基础元件，东京科学大学的成果证明了CMOS在太赫兹频段的量产可行性，这对中兴未来布局6G太赫兹终端芯片具有参考价值。中兴在3GPP NTN和6G标准中非常活跃，300 GHz CMOS相控阵是6G标准的前置技术，建议提前储备。
