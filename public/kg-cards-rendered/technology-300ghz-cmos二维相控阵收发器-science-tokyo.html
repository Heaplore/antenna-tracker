300GHz CMOS二维相控阵收发器-Science Tokyo

东京科学大学冈田健一教授团队在2026 IEEE/JSAP VLSI Circuits会议上发表世界首款300GHz全CMOS二维4×4相控阵收发器IC，将16路双通道收发电路加片上天线集成在同一65nm芯片上，单素子功耗仅26mW、面积0.30mm²，实现±32°双向波束扫描，为6G太赫兹通信低成本量产铺平道路。

一、主题概述

300GHz频段属于太赫兹带下限区域（300GHz–3THz），是IEEE 802.15.3d标准定义的252–325GHz频段核心部分，拥有超大带宽潜力（理论上可达100+ Gbps），但面临自由空间路径损耗极大（比2.4GHz高出约40dB）和集成密度极限两大挑战。半波长远小于1mm，天线与收发电路难以在同一芯片上紧凑排布。东京科学大学采用65nm CMOS工艺实现全集成300GHz二维相控阵收发器，且天线间距达到严格半波长，证明即使CMOS高频性能有限，通过架构创新也能实现实用通信。

2.1 300GHz频段的物理挑战与机遇

300GHz频段（300 GHz – 3 THz）属于太赫兹带下限区域，是IEEE 802.15.3d标准定义的252–325GHz频段核心部分。这一频段拥有巨大的频谱资源——理论上可提供100+ Gbps的传输速率，远超5G毫米波的数Gbps水平。然而，300GHz频段也带来了前所未有的物理挑战。

自由空间路径损耗分析： 根据Friis传输方程，自由空间路径损耗为：

L_fs(dB) = 20log₁₀(4πd/λ) = 20log₁₀(d) + 20log₁₀(f) + 92.45

其中d单位为km，f单位为GHz。

距离 2.4GHz损耗 28GHz损耗 300GHz损耗 300GHz相对增量
1m 40dB 69dB 100dB +31dB
10m 60dB 89dB 120dB +31dB
100m 80dB 109dB 140dB +31dB

相比Sub-6GHz频段，300GHz路径损耗高出约40dB，这意味着需要极高增益的天线阵列来补偿。同时，大气吸收峰值（氧气吸收峰在60GHz和118GHz附近，但300GHz处仍有显著吸收）进一步限制了传播距离。因此，300GHz通信主要面向短距高速场景——室内Femtocell、机房互联、固定无线接入等。

半波长的工程挑战： 300GHz波长λ = c/f = 3×10⁸/300×10⁹ = 1mm，半波长仅约0.5mm。这意味着：

  • 天线单元尺寸必须控制在亚毫米级别
  • 阵列间距必须精确控制，否则会产生栅瓣（grating lobe）——波束分裂成多个方向，失去定向性
  • PCB布线的线宽和间距需要达到精密加工水平

CMOS工艺在300GHz的限制：

  • 65nm CMOS的fT/fmax约300/400GHz，接近频率上限
  • 有源器件增益有限（约10-15dB）
  • 无源器件（电感、电容）Q值较低（约10-20）
  • 需要通过架构创新弥补工艺限制

2.2 片上天线设计与背腔结构创新

本研究的核心创新之一是基板背面沟槽加工形成半独立腔体。传统CMOS芯片的天线如果直接制作在硅基底上，会有两个严重问题：

  1. 基板损耗：硅基底在太赫兹频段具有显著的介电损耗（tanδ ≈ 0.01-0.1），导致辐射能量被硅吸收转化为热能
  2. 表面波激发：电磁波会在硅-空气界面激发表面波，降低辐射效率

背腔结构的解决方案： 通过在硅基板背面加工深沟槽（深度约200-300μm），形成半独立的声学/电磁腔体。这个腔体的作用是：

  • 抑制基板模式：阻断表面波在硅基底中的传播路径
  • 提高辐射效率：将电磁波辐射方向改为基板背面，减少正面互耦
  • 增益提升：实测数据显示，背腔结构使天线增益平均提升4dB

天线单元采用偶极子天线设计，这是太赫兹频段最常用的辐射单元之一。偶极子天线的优势在于：

  • 结构简单，易于集成
  • 阻抗带宽相对较宽（约10-20%）
  • 偏振纯净度高（交叉极化比>20dB）

偶极子天线设计参数：

  • 臂长：约0.48mm（接近半波长）
  • 臂宽：约50μm
  • 间隙：约20μm
  • 输入阻抗：约200Ω（需匹配至50Ω）

2.3 半波长间距集成与栅瓣抑制

栅瓣的数学条件： 对于均匀线阵，栅瓣出现的条件为：

|sin(θ_s) - sin(θ_0)| = mλ/d, m = ±1, ±2, ...

其中θ_s是栅瓣角度，θ_0是主瓣角度，d是单元间距。

当d > λ/2时，即使θ_0 = 0（法向辐射），也存在m ≠ 0的整数解，即出现栅瓣。为避免栅瓣，必须满足：

d ≤ λ/2

本研究实现了E面0.49λ、H面0.50λ的严格半波长间距。这一精度要求非常高——在300GHz频段，半波长仅0.5mm，制造公差必须控制在±10μm以内。这需要通过高精度的光刻工艺实现。

互耦分析： 半波长间距下，单元间互耦系数约-15dB至-20dB，处于可接受范围。但需考虑：

  • 有源单元方向图（Active Element Pattern）变化
  • 互耦导致的相位误差（<5°）
  • 端口匹配恶化（S11 < -10dB）

2.4 收发共享双通道架构

架构创新：TX/RX共用同一套天线，无需开关切换。传统设计通常在TX和RX路径之间放置射频开关，但这会引入额外的插入损耗（约0.5-1dB）和复杂度。本研究采用共享天线设计，简化了架构。

发射端架构：

数字基带 → 移相器 → 倍频器 → 注入锁定三倍频器(ILT) → 天线
  • 移相器：实现波束赋形，相位控制精度为5.625°（2^5 bit）
  • 倍频器：将本振频率从100GHz倍频至300GHz
  • 注入锁定三倍频器（ILT）：这是关键创新。传统倍频器效率低（约10-20%），而ILT通过注入锁定技术，将倍频效率提升至50%以上，同时改善输出频谱纯度

ILT技术原理： 注入锁定是一种非线性动力学现象，当注入信号频率接近振荡器固有频率时，振荡器会被"锁定"到注入频率。ILT利用这一原理：

  • 注入信号：100GHz（来自VCO）
  • 振荡器：设计在300GHz谐振
  • 锁定范围：约10-20GHz
  • 效率提升：从15%提升至55%

接收端架构：

天线 → 次谐波混频器 → LNA → 中频输出

采用mixer-first架构，即混频器直接位于天线之后，避免了传统接收机中LNA-混频器的级联损耗问题。

功耗分析： 单素子功耗26mW，16个素子总功耗约416mW。这个功耗水平远低于传统GaAs/GaN方案的瓦级功耗，证明了CMOS工艺在太赫兹频段的能效优势。

增益计算： 4×4阵列的理论阵列增益为：

G_array = G_element + 10log₁₀(N)

其中G_element是单素子增益（约6dBi），N是单元数（16）。因此理论阵列增益约为6 + 12 = 18dBi。结合背腔结构提升的4dB，实际增益可达约22dBi。

波束赋形算法： 采用基于离散傅里叶变换（DFT）的波束赋形算法：

w_n = exp(j·2π·n·sin(θ)/λ), n = 0,1,...,N-1

其中θ为目标波束方向，n为阵元索引。通过调整相位权重，可实现波束指向控制。

3.1 应用场景分析与适用性评估

室内Femtocell（极高适用性★★★★★）： 300GHz相控阵收发器最适合的应用场景是室内短距高速通信。在一个典型的300m²办公室内，信号传播距离约10-30米，路径损耗约120-130dB。结合22dBi的阵列增益和-17dBm的EIRP，系统链路预算充足。二维波束扫描（±32°）可以覆盖整个房间，实现无死角覆盖。

机房/数据中心互联（高适用性★★★★☆）： 服务器机架之间的互联是300GHz的天然应用场景。传统光纤耦合需要布线，而300GHz无线互联可以实现免布线的高速数据传输。单通道16Gbaud QPSK调制可提供约32Gbps的净速率，16路并行可达512Gbps。低功耗（416mW总功耗）和小型化（4.8mm²芯片）是显著优势。

无人机/移动终端（高适用性★★★★☆）： 无人机和移动终端对重量和功耗极度敏感。本方案的单素子功耗仅26mW，16单元总功耗416mW，远低于传统GaN方案的瓦级功耗。芯片尺寸仅4.8mm²，可以轻松集成到无人机机身或移动设备中。

6G太赫兹固定无线接入FWA（中高适用性★★★★☆）： 点对点100+ Gbps回传是6G FWA的重要应用场景。当前4×4阵列的EIRP（-17dBm）对于短距（<100m）点对点通信足够，但要实现更长距离需要更大规模阵列（16×16或64×64）。

机器人/工厂内无线（中高适用性★★★★☆）： 工业机器人在生产线上的高速数据传输需要免布线解决方案。300GHz相控阵可以提供Gbps级带宽，且二维波束扫描可以跟踪移动机器人。

室外宏站（中适用性★★★☆☆）： 室外宏站需要覆盖数百米至数公里，当前4×4阵列的EIRP不足。需要更大规模阵列（64×64或更大）和高功率放大器。但CMOS的低成本优势使其在大规模部署中具有潜力。

卫星终端（低适用性★★☆☆☆）： 卫星通信需要极高的EIRP（>50dBm）和极高的接收灵敏度。当前方案的-17dBm EIRP相差甚远。但作为卫星终端的本地互联或星载短距通信，CMOS相控阵具有成本优势。

3.3 产业化路径分析

短期（1-2年）：实验室验证和小规模试点。主要用于数据中心内部互联、机器人无线通信等封闭场景。

中期（3-5年）：5G-A/6G太赫兹频段标准化后，进入商用试点。可能首先在室内Femtocell和固定无线接入场景中部署。

长期（5年以上）：与RIS技术融合，形成6G太赫兹通信网络。CMOS相控阵芯片可能成为6G终端和基站的标准组件。

五、趋势判断

CMOS是太赫兹量产唯一路径——GaN/GaAs性能更好但成本太高，65nm CMOS在300GHz已实现实用性能，28nm及以下节点将进一步突破频率上限。从4×4到更大规模是必然趋势，当前4×4只是验证芯片级集成可行性，未来16×16甚至64×64的片上相控阵将成为基站AAU核心前端。三维堆叠加片上天线是必由之路，传统PCB布线在300GHz已不可行。与RIS可能融合——东京科学大学的CMOS相控阵加首尔大学的STARE晶圆级RIS两条路线可能在6G太赫兹系统中融合。台积电28nm/16nm节点有望进一步将频率上限推至400-500GHz。

六、与老大的关联

老大参与的中兴GigaMIMO项目聚焦亚6G/U6G频段，300GHz太赫兹是GigaMIMO的自然延伸——从亚6G到UWB再到太赫兹，天线规模从千级向万级演进。中兴在毫米波专利布局上已有深厚积累，300GHz方向值得提前卡位。本篇笔记是继STARE晶圆级RIS之后的又一半导体级天线突破，三条路线正在收敛：半导体工艺进步让天线从"外挂模块"变成"片上集成"，对中兴6G研发方向有直接参考价值。中兴目前的Pre6G重心在GigaMIMO和低空通感，300GHz太赫兹属于更后期技术储备，但CMOS相控阵芯片是终端侧和基站侧共同基础元件，东京科学大学成果证明了CMOS在太赫兹频段的量产可行性，建议提前储备。
