Active-BD-RIS有源超对角智能超表面

Active BD-RIS将信号放大引入超对角RIS，从根本上缓解被动RIS的乘性路径损耗问题，所需元件数仅为Active Diagonal RIS的一半，增益提升可达10-15dB。

一、主题概述

Active BD-RIS 是RIS 2.0架构的重要演进方向，核心创新在于将信号放大引入超对角RIS，从根本上缓解被动RIS的乘性路径损耗问题。

被动RIS面临的核心瓶颈是：信号经过RIS二次反射后，路径损耗呈平方衰减（乘性路径损耗）。以典型场景为例，基站到RIS的距离d₁和RIS到用户的距离d₂，总路径损耗为$(d_1 \cdot d_2)^2$，远高于直达路径损耗$d^2$。这种"双重损耗"使得被动RIS在远距离场景下增益有限。

Active BD-RIS通过在每个元件或分组中集成放大器，实现信号增益，使RIS从"纯反射"走向"智能反射+放大"。本文聚焦2026年3-4月连续发表的三篇arXiv论文，系统梳理Active BD-RIS的建模、架构设计与优化方法。

1. 基本问题：乘性路径损耗的数学本质

被动RIS的信道模型为：

$$y = \mathbf{h}_d^H \mathbf{x} + \mathbf{h}_r^H \mathbf{\Phi} \mathbf{G} \mathbf{x} + n$$

其中：

  • $\mathbf{h}_d \in \mathbb{C}^{N_r \times N_t}$ 是直接链路信道（基站→用户）
  • $\mathbf{G} \in \mathbb{C}^{N_r \times N}$ 是基站→RIS链路
  • $\mathbf{h}_r \in \mathbb{C}^{N_r \times N}$ 是RIS→用户链路
  • $\mathbf{\Phi} = \text{diag}(\beta_1 e^{j\theta_1}, ..., \beta_N e^{j\theta_N})$ 是RIS反射矩阵
  • $N$ 是RIS元件数，$N_r$、$N_t$ 分别是接收和发射天线数

关键问题在于第二项的增益与 $\mathbf{\Phi}$ 的元素模长平方成正比：

  • 每个元件的反射系数$|\beta_n| \leq 1$（被动元件）
  • 总增益正比于$|\mathbf{h}_r^H \mathbf{\Phi} \mathbf{G}|^2 \propto N^2 \cdot |\beta|^2$
  • 但路径损耗正比于$(d_1 \cdot d_2)^2$
  • 当$N^2 \cdot |\beta|^2 < (d_1 \cdot d_2)^2 / d^2$时，RIS辅助链路还不如直达链路

这就是乘性路径损耗问题的本质：RIS的阵列增益被平方衰减的路径损耗抵消。

具体而言，路径损耗模型为：

$$PL = PL_d + PL_r + PL_s = 20\log_{10}(d_d) + 20\log_{10}(d_r) + 20\log_{10}(d_s) + C$$

其中$d_d$是直连距离，$d_r$是RIS到用户距离，$d_s$是基站到RIS距离，C是常数项。对于RIS辅助链路，总路径损耗为$(d_s \cdot d_r)^2$，而阵列增益为$N^2$（理想情况）。当$d_s \cdot d_r > N \cdot d_d$时，RIS辅助链路性能不如直连链路。

2. Active BD-RIS建模（arXiv:2603.13861）详解

这是第一篇系统建立Active BD-RIS模型的论文，由利物浦大学、HKUST广州校区和Imperial College联合完成。

散射参数建模： 使用S参数描述Active BD-RIS的多端口网络特性。传统RIS的反射矩阵是对角矩阵$\mathbf{\Phi} = \text{diag}(\beta_1, ..., \beta_N)$，每个元件独立控制。而BD-RIS的反射矩阵是非对角的$\mathbf{\Theta} \in \mathbb{C}^{N \times N}$，元件之间存在互耦。

Active BD-RIS的散射矩阵： $$\mathbf{S} = \begin{bmatrix} \mathbf{S}{RR} & \mathbf{S}{RT} \ \mathbf{S}{TR} & \mathbf{S}{TT} \end{bmatrix}$$ 其中$\mathbf{S}{RR}$是反射端口间的散射参数（非对角，体现BD特性），$\mathbf{S}{RT}$和$\mathbf{S}{TR}$是反射-透射耦合，$\mathbf{S}{TT}$是透射端口间的散射参数。

具体地，散射矩阵S的第i行第j列元素S_ij表示从端口j入射、从端口i出射的反射/透射系数。对于全连接架构，S矩阵的非对角元素S_ij (i≠j)代表元件间的互耦效应，这些互耦项使得BD-RIS相比传统对角RIS具有更强的波束控制能力。

两种架构详解：

  1. 全连接Active BD-RIS：所有N个元件端口通过可调负载网络互连，散射矩阵$\mathbf{S}_{RR}$的非对角元素自由可调。理论上最优，但硬件复杂度为O(N²)。
  2. 优点：波束控制能力最强，可实现任意波束形状和零陷位置
  3. 缺点：需要N²个可调负载，硬件复杂度高

  4. 适用场景：高性能需求场景，如基站侧部署

  5. 分组连接Active BD-RIS：将N个元件分成G组，组内元件互连，组间独立。硬件复杂度降为O(N²/G)，性能接近全连接方案。

  6. 假设有K个组，每组包含N/K个元件
  7. 可调负载数量从N²降到KN/K = KN
  8. 组间通过有源放大网络连接，实现组间的信号合成
  9. 适用场景：成本敏感场景，如室内覆盖增强

关键结论：

  • SISO系统：推导了SNR的闭式最优解，给出缩放律$SNR \propto N^2$（理想无噪声情况）
  • MIMO系统：提出基于QCQP（二次约束二次规划）的迭代算法最大化频谱效率
  • 收敛性：算法单调收敛，每次迭代都不降低目标函数

具体而言，对于SISO系统，接收信噪比为：

$$SNR = \frac{P_t |\mathbf{h}_r^H \mathbf{\Theta} \mathbf{G} \mathbf{w}|^2}{\sigma^2}$$

其中$P_t$是发射功率，$\mathbf{w}$是发射预编码向量，$\sigma^2$是噪声功率。优化$\mathbf{\Theta}$可以得到闭式最优解，使得SNR随N²增长。

性能优势量化：

  • 达到相同频谱效率，Active BD-RIS所需元件数少于Active Diagonal RIS的一半
  • 例如：达到100 Mbps速率，Active Diagonal RIS需要200个元件，Active BD-RIS仅需80-100个
  • 相比被动BD-RIS，增益提升可达10-15dB（取决于放大器配置）
  • 相比被动Diagonal RIS，增益提升可达15-20dB

3. 混合透射反射模式（arXiv:2604.13570）详解

这篇论文由HKUST广州独立完成，核心创新是让Active BD-RIS同时支持反射和透射模式。

架构设计：

  • 收发双向激活：反射支路和透射支路均含放大器
  • 功率分配机制：可调功分器控制反射/透射功率比例，反射功率占比$\alpha$，透射功率占比$1-\alpha$
  • 独立波束控制：反射波束和透射波束可独立steering，指向不同用户

数学建模： 对于N元件Active BD-RIS，反射系数矩阵$\mathbf{\Theta}r$和透射系数矩阵$\mathbf{\Theta}_t$满足约束： $$|\theta{r,n}|^2 + |\theta_{t,n}|^2 \leq 1, \quad \forall n$$ 这表示每个元件的反射和透射功率之和不超过入射功率（无源情况），或有源情况下可以大于1（增益>1）。

优化框架：

  • 联合发射预编码$\mathbf{W}$和Active BD-RIS设计$\mathbf{\Theta}_r, \mathbf{\Theta}_t$
  • 目标函数：多用户Sum-rate最大化
  • 约束条件：发射功率、RIS功率、反射/透射功率分配
  • 算法：交替优化（AO），固定一部分优化另一部分，直至收敛

目标函数可表示为：

$$\max_{\mathbf{W}, \mathbf{\Theta}r, \mathbf{\Theta}_t} \sum{k=1}^{K} R_k$$

其中$R_k$是第k个用户的速率，约束条件包括：

  • 发射功率约束：$tr(\mathbf{W}\mathbf{W}^H) \leq P_{max}$
  • RIS功率约束：$\sum_n (|\theta_{r,n}|^2 + |\theta_{t,n}|^2) \leq P_{RIS}$
  • 反射/透射功率分配约束：$|\theta_{r,n}|^2 + |\theta_{t,n}|^2 \leq 1 + G_n$，其中$G_n$是第n个元件的增益

仿真结果：Active BD-RIS混合模式比被动STAR-RIS提升约3-5倍中继链路速率。

4. STAR BD-RIS with Amplification（arXiv:2603.06020）详解

这篇论文由卢森堡大学、雅典国立大学和帕多瓦大学联合完成，提出同时透射反射BD-RIS（STAR BD-RIS）的放大版本。

模型特点：

  • 解耦三个维度：
  • 放大：对角增益矩阵$\mathbf{A} = \text{diag}(a_1, ..., a_N)$，$a_n \geq 1$表示增益
  • 元件级反射/透射功率分配：每个元件的反射系数$\theta_{r,n}$和透射系数$\theta_{t,n}$

  • 无损耗功率分配的被动BD耦合：非对角耦合矩阵$\mathbf{\Theta}$

  • 施加实际约束：

  • 单元件发射功率上限：$|\theta_{r,n}|^2 + |\theta_{t,n}|^2 \leq P_{max}$
  • RIS总功率预算：$\sum_n (|\theta_{r,n}|^2 + |\theta_{t,n}|^2) \leq P_{RIS}$

优化方法：

  • WMMSE（Weighted Minimum Mean Square Error）等价转换：将Sum-rate最大化转化为加权MSE最小化
  • 交替优化框架：
  • 固定RIS参数，优化MMSE接收器（闭式解）
  • 固定接收器，优化权重（闭式解）
  • 固定接收器和权重，优化RIS参数（Riemannian梯度下降）
  • 单调下降保证收敛：每次迭代目标函数不降低

Riemannian优化细节： BD耦合矩阵$\mathbf{\Theta}$约束为Stiefel流形（列正交矩阵），使用Riemannian梯度下降在流形上优化：

  • 梯度计算：在切空间中计算目标函数的梯度
  • 投影：将梯度投影回切空间
  • 回撤：使用重traction算子将切空间点映射回流形

具体而言，Stiefel流形$St(N, r) = {\mathbf{X} \in \mathbb{R}^{N \times r} : \mathbf{X}^T\mathbf{X} = \mathbf{I}_r}$上的优化需要特殊的梯度投影和回撤操作。

性能增益量化：

  • 相比被动BD-RIS，Sum-rate提升2-3倍（仿真结果）
  • 优于传统Active STAR-RIS（对角架构）约1.5倍
  • 在50元件系统中，Active STAR BD-RIS可实现10倍于被动STAR-RIS的速率

6. 关键挑战

硬件实现挑战：

  • 放大器噪声系数：当前约3-6 dB，需降至1-2 dB
  • 线性度：IP3（三阶截点）需>20 dBm
  • 功耗平衡：每元件功耗约100-200 mW，N元件系统总功耗10-20 W
  • 散热：高密度集成下的热管理

信道估计挑战：

  • Active BD-RIS增加未知参数（增益+相位），CE复杂度上升
  • 需要新的导频设计和估计算法
  • 实时CE是工程化关键

1. 6G覆盖增强场景详解

室内深度覆盖： - 场景：大型办公楼、商场、工厂内部 - 问题：墙壁穿透损耗10-20 dB，角落盲区信号弱 - Active BD-RIS方案：部署于墙壁/天花板，放大信号弥补穿透损耗 - 增益：相比被动RIS，盲区覆盖率提升30-50%

具体而言，室内穿透损耗可以用以下模型估算：

$$PL_{wall} = 10\log_{10}\left(\frac{1}{T}\right)$$

其中T是墙壁的透射系数。对于混凝土墙，T≈0.01-0.1，因此PL_wall≈10-20 dB。Active BD-RIS的放大器可以补偿这部分损耗。

室外盲区补盲： - 场景：城市峡谷、隧道入口、山区基站阴影区 - 问题：直射路径被遮挡，传统方案需部署额外微站 - Active BD-RIS方案：作为"虚拟基站"，放大并反射信号绕过障碍 - 成本：比部署物理微站便宜60-80%

高频段（mmWave/THz）应用： - 28 GHz/mmWave：路径损耗约$L = (4\pi d/\lambda)^2$，1km距离损耗约140 dB - 太赫兹：路径损耗更严重，100 GHz时1km损耗达160 dB - Active BD-RIS增益价值更大：放大器的引入直接弥补路径损耗

在28 GHz频段，自由空间路径损耗为：

$$PL(dB) = 20\log_{10}(d) + 20\log_{10}(f) + 20\log_{10}(4\pi/c)$$

其中d是距离（km），f是频率（GHz）。当d=1km，f=28GHz时，PL≈140 dB。

2. 通感一体化（ISAC）应用

Active BD-RIS可同时服务通信和感知，这是其独特优势：

通信-感知波束分离： - 反射波束：服务于通信用户 - 透射波束：服务于感知目标（或反之） - 独立steering：两个波束可指向不同方向

感知性能提升： - 放大后的反射信号提升感知信噪比 - 感知分辨率：$\Delta R = c/(2B)$，$\Delta \theta = \lambda/(ND\cos\theta)$ - Active BD-RIS的增益使得远距离感知成为可能（>1km）

应用场景： - 智能驾驶：道路边缘部署Active BD-RIS，感知行人、车辆 - 工业监控：工厂内部部署，感知设备状态、人员位置 - 安防监控：周界部署，感知入侵者

具体而言，感知距离分辨率和角度分辨率分别为：

$$\Delta R = \frac{c}{2B}, \quad \Delta \theta = \frac{\lambda}{ND\cos\theta}$$

其中B是信号带宽，N是阵列元素数，D是阵列孔径。Active BD-RIS的增益可以提升感知信噪比，从而延伸感知距离。

3. 卫星互联网回传

低轨卫星高速移动（7.66 km/s @ 550km高度），传统波束跟踪困难：

问题： - 卫星过顶时间约10分钟 - 波束切换频率高（每秒数次） - 地面站数量有限

Active BD-RIS解决方案： - 静态部署于地面，波束切换速度快（μs级） - 放大能力弥补长距离路径损耗（550km + 大气损耗） - 多个Active BD-RIS协同覆盖，减少地面站数量

性能估算： - 550km距离，28 GHz频段，路径损耗约190 dB - 主动放大补偿50-60 dB，使得可用链路预算可达 - 单Active BD-RIS可服务多个卫星过境

4. 车联网（V2X）应用

高速公路场景：车辆速度30-120 km/h，信道快变：

道路边缘部署： - 沿高速公路每500m部署一个Active BD-RIS - 实时调整形态补偿车辆高速移动导致的信道快衰落 - 放大能力应对车辆快速移动导致的信道快变

双链路支持： - 反射链路：车-基础设施（V2I），服务路口信号、限速提示 - 透射链路：车-车（V2V），服务前方车辆预警、编队行驶

性能优势： - 相比传统蜂窝V2X，延迟降低50%（从10ms降至5ms） - 可靠性提升：多Active BD-RIS协同，冗余覆盖

5. 其他应用场景

紧急通信： - 灾害发生后传统基站损坏，Active BD-RIS可快速部署恢复通信 - 无人机搭载Active BD-RIS，临时覆盖灾区

偏远地区覆盖： - 山地、海岛等偏远地区，部署成本高 - Active BD-RIS作为中继，覆盖范围扩展3-5倍

室内定位： - 利用Active BD-RIS的波束指向信息，实现厘米级定位 - 商场、仓库等场景的室内导航

  6. 信道估计：

  7. Active BD-RIS增加未知参数（增益+相位），CE复杂度上升
  8. 需要新的导频设计和估计算法

  9. 实时CE是工程化关键

  10. 标准化：

  11. 3GPP Rel-19未纳入RIS，Rel-20可能启动Study Item
  12. ETSI ISG RIS正在制定被动RIS标准
  13. Active BD-RIS需要新的标准化框架

与老大的关联

老大关注RIS工程化，Active BD-RIS是下一阶段关键技术：

  • 理论层面：Clerckx团队已建立完整理论框架，可借鉴优化方法
  • 硬件层面：需评估放大器集成方案（每元件 vs 分组）
  • 标准化层面：关注ETSI ISG RIS进展，国内推进组可能抢先布局
  • 产业化层面：2-3年的gap意味着现在是布局的最佳时机

对中国产业的启示

  1. 弯道超车机会：被动RIS中国已领先（华为、中兴），Active BD-RIS是新的竞争点
  2. 专利布局：三篇核心论文的作者机构尚未大规模申请专利，存在布局窗口
  3. 产学研合作：利物浦大学、HKUST广州、Imperial College是核心研究团队，可考虑合作
  4. 标准化参与：建议国内机构积极参与ETSI ISG RIS，推动Active BD-RIS纳入标准
