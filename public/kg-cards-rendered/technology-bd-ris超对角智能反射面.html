BD-RIS超对角智能反射面

BD-RIS是RIS 2.0的核心架构，突破传统对角RIS各元素互不连接的限制，通过引入可调阻抗网络实现元素间耦合，使散射矩阵的非对角元素非零，从而同时控制入射波的振幅和相位，大幅提升波束操控灵活性和频谱效率。

天线技术技术概念RIS6G超表面波束赋形

1.1 从对角RIS到超对角RIS

传统RIS（RIS 1.0）采用单连架构（single-connected），每个可重构单元独立连接到可调阻抗负载，单元之间无电气连接。其散射矩阵为对角矩阵：

$$\mathbf{\Phi} = \text{diag}[\beta_1 e^{j\theta_1}, \beta_2 e^{j\theta_2}, \ldots, \beta_N e^{j\theta_N}]$$

其中 $\beta_n$ 和 $\theta_n$ 分别为第n个单元的振幅反射系数和相位偏移，各单元独立控制，互不干扰。

BD-RIS（RIS 2.0）的核心创新在于引入可调阻抗网络，使单元之间产生耦合：

$$\mathbf{\Phi} \in \mathbb{C}^{N \times N}, \quad \mathbf{\Phi} \neq \text{diag}(\cdot)$$

散射矩阵的非对角元素 $\Phi_{nm} (n \neq m)$ 表示单元m对单元n的信号耦合，这使得BD-RIS能够：

  • 同时调控振幅和相位
  • 实现更复杂的波前整形
  • 在相同元件数下获得更高的性能增益

1.2 多端口网络理论建模

BD-RIS的严格物理建模基于多端口网络理论：

$$\mathbf{b} = \mathbf{\Gamma} \mathbf{a}$$

其中 $\mathbf{a}$ 为入射波向量，$\mathbf{b}$ 为出射波向量，$\mathbf{\Gamma}$ 为散射矩阵。BD-RIS通过可调阻抗网络 $\mathbf{Z}_L$ 实现：

$$\mathbf{\Gamma} = (\mathbf{I} + \mathbf{Z}_0^{-1}\mathbf{Z}_L)^{-1}(\mathbf{I} - \mathbf{Z}_0^{-1}\mathbf{Z}_L)$$

其中 $\mathbf{Z}_0$ 为参考阻抗，$\mathbf{Z}_L$ 为负载阻抗矩阵（包含单元间耦合项）。

2.1 BD-RIS三种架构类型

架构类型 连接方式 自由度 复杂度 性能增益
单连（对角） 无互连 N 最低 基准
分组连（Group-Connected） 组内互连，组间隔离 N 中等 2-3倍
全连（Fully-Connected） 全部互连 N(N+1)/2 最高 5-10倍

分组连架构：将N个单元分为K组，组内单元通过阻抗网络互连，组间无连接：

  • 每组内部形成子散射矩阵 $\mathbf{\Phi}_k \in \mathbb{C}^{(N/K) \times (N/K)}$
  • 整体散射矩阵为分块对角矩阵
  • 设计复杂度远低于全连架构

全连架构：所有单元通过可调阻抗网络完全互连：

  • 散射矩阵完全非对角
  • 提供最大设计自由度
  • 硬件实现难度最高

2.2 性能优势量化

SISO系统信噪比_scaling law：

对于单输入单输出系统，BD-RIS提供的信噪比增益为：

$$\text{SNR}_{\text{BD-RIS}} = \frac{P_t |h_d + \mathbf{a}^H \mathbf{\Phi} \mathbf{b}|^2}{\sigma^2}$$

其中 $\mathbf{a}$ 为发射端到RIS的通道向量，$\mathbf{b}$ 为RIS到接收端的通道向量。

数值仿真表明：

  • 实现相同频谱效率，Active BD-RIS所需元件数 < Active对角RIS的50%
  • 在N=100单元场景下，分组连BD-RIS相比对角RIS可获得约3dB增益
  • 全连BD-RIS相比对角RIS可获得约6-8dB增益

2.3 BD-RIS信道估计复杂度

与传统对角RIS相比，BD-RIS的信道估计开销处于同一数量级：

$$\mathcal{O}(N) \text{ vs } \mathcal{O}(N^2)$$

研究表明，BD-RIS的信道估计复杂度可通过分组策略降低至与对角RIS相当的水平。

3.1 硬件实现路线

被动BD-RIS：

  • 采用可变电容/电感网络实现单元间耦合
  • 无源器件，低功耗
  • 面临乘法路径损耗问题

有源BD-RIS（Active BD-RIS）：

  • 在可调阻抗网络中集成放大单元
  • 克服乘法损耗，提供信号增益
  • 功耗和热管理挑战更大

STAR BD-RIS（透射-反射超对角RIS）：

  • 同时实现透射和反射波束赋形
  • 提供360°全空间覆盖
  • 散射矩阵为4×4分块结构

3.2 优化算法

单用户MISO系统闭式解： $$\max_{\mathbf{\Phi}} |\mathbf{h}_d^H \mathbf{\Phi} \mathbf{h}_t|^2 \quad \text{s.t.} \quad \mathbf{\Phi} \in \mathcal{S}$$

其中 $\mathcal{S}$ 为BD-RIS物理可实现集合。

多用户MIMO系统优化：

  • 基于二次约束二次规划（QCQP）的迭代算法
  • 交替优化框架：固定RIS配置优化波束赋形，固定波束赋形优化RIS配置

黎曼流形优化：

  • 针对BD-RIS的复Stiefel流形约束
  • 使用QR/极性折返方法的梯度步长

6.1 互耦效应建模

  • 传统RIS设计忽略单元间互耦，BD-RIS必须精确建模
  • 近场互耦导致散射矩阵非线性，需电磁仿真验证

6.2 量化效应

  • 实际阻抗网络只有有限位分辨率（如1-bit、2-bit）
  • 全连架构对量化误差更敏感

6.3 热管理

  • 有源BD-RIS的放大单元带来额外热负荷
  • 密集集成导致散热困难

6.4 标准化滞后

  • 3GPP Release 19尚未纳入BD-RIS规范
  • ETSI ISG RIS有预标准报告，但工程指南缺失

七、技术演进

  • RIS 1.0对角架构（2018-2022）：单连架构，仅相位调控，理论分析成熟但性能受限
  • BD-RIS概念提出（2022-2023）：Imperial College伦敦提出超对角架构，引发学术界关注
  • 架构分类确立（2024）：单连/分组连/全连三类架构明确，物理一致性模型建立
  • Active BD-RIS突破（2025-2026）：有源版本解决乘法损耗问题，STAR BD-RIS实现全空间覆盖
  • 标准化推进（2026-）：ETSI ISG RIS纳入BD-RIS预标准，3GPP Release 20预期纳入

学术研究前沿

  • Imperial College London（Bruno Clerckx团队）：BD-RIS理论奠基者，主导UKRI EP/Y004086/1项目

产业动向

  • ETSI ISG RIS：已将BD-RIS纳入预标准技术报告

  • VIAVI Solutions：测试测量方案供应商

与老大的关联

  • BD-RIS与老大研究的RIS有源智能超表面方向高度相关
  • 分组连架构是工程化落地的优先选择，值得重点关注
  • Active BD-RIS解决乘法损耗问题，对6G通感一体化部署有直接参考价值

十一、与老大的关联

BD-RIS是RIS技术从1.0到2.0的关键跃迁，与老大的研究方向（RIS有源智能超表面、逆拓扑设计）高度契合：

  1. 理论层面：BD-RIS打破了传统对角RIS的局限性，为有源RIS设计提供更灵活的波束赋形空间
  2. 工程层面：分组连架构是兼顾性能与复杂度的折中方案，适合作为RIS 2.0的候选架构
  3. 产业层面：ETSI已启动BD-RIS预标准工作，中兴作为6G研发主力需关注标准动向
  4. 差异化机会：Active BD-RIS的有源设计、STAR BD-RIS的全空间覆盖、BD-RIS与ISAC融合，都是值得深耕的细分方向
