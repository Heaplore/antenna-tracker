近场XL-MIMO距离-角度解耦波束赋形RAD

近场XL-MIMO的信道同时依赖角度和距离，RAD方法利用Fresnel三分解将球面波前拆成范围聚焦项和角度项，实现两阶段解耦预编码，把反馈开销从O(N)降到O(1)，同时保持多用户干扰对消能力。

核心问题

6G XL-MIMO系统中，超大规模阵列使Fraunhofer距离扩展到数百米甚至数公里，大量用户落入辐射近场。近场信道具有联合角度-距离依赖性：

$$h_n = \frac{e^{-jk|\mathbf{r} - \mathbf{r}_n|}}{|\mathbf{r} - \mathbf{r}_n|}$$

其中 $\mathbf{r}$ 为用户三维位置，$\mathbf{r}_n$ 为第 $n$ 个阵元位置。这与远场平面波近似 $e^{-jkR_0} e^{j\mathbf{\hat{s}}\cdot\mathbf{r}}$ 有本质区别。Fraunhofer距离定义为 $R_F = \frac{2D^2}{\lambda}$，当阵列孔径 $D = 1$ m、频率 $f = 100$ GHz 时，$R_F \approx 600$ m，意味着城市微站场景下几乎所有用户都落在近场区。

传统预编码（MRT、ZF）基于远场 steering vector 仅依赖角度，存在两个根本性问题：

  1. 单用户相干增益损失：用户越靠近阵列中心，球面波前曲率越大，平面波假设偏差越大，MRT/ZF 的增益损失随深度增加而放大
  2. 多用户干扰不可区分：角度相同但距离不同的用户在平面波模型下完全重叠，ZF 无法对消这类干扰

解决方案：Range-Angle Decoupled (RAD) Beamforming

核心思路是将近场信道的球面波前通过 Fresnel 三分解 拆解为三个独立因子：

$$h(\mathbf{r}) \approx f_{\text{range}}(R) \cdot f_{\text{coupling}}(R, \theta) \cdot f_{\text{angle}}(\theta)$$

  • $f_{\text{range}}(R)$：距离相关的二次相位项（球面波曲率补偿），形式为 $e^{jk\frac{|\mathbf{r}_n|^2}{2R}}$
  • $f_{\text{coupling}}(R, \theta)$：距离-角度交叉耦合项（可预补偿），源于斜入射路径差异
  • $f_{\text{angle}}(\theta)$：纯角度 steering vector（与远场形式一致）

经过分解后，预编码分为两个顺序阶段：

阶段一：范围聚焦（Range-Focusing）

对每个用户施加距离相关的相位补偿，抵消球面波曲率，将用户"拉平"到等效远场位置。这一步相当于在距离域做准直，使得原本因球面波前不同曲率而产生的相位失配被消除。数学上，对第 $k$ 个用户，施加的聚焦权重为 $w_n^{(k)} = e^{jk\frac{|\mathbf{r}_n - \mathbf{r}_k|^2 - |\mathbf{r}_n|^2}{2R_k}}$，其中 $R_k = |\mathbf{r}_k|$。

阶段二：角度域零陷（Angle-Domain Nulling）

在距离补偿后的域中，使用经典 ZF/MRT 预编码进行角度域多用户干扰对消。此时 steering vector 退化为纯角度依赖，远场算法可直接复用。

低反馈机制

传统近场预编码需要基站向UE反馈 O(N) 个复系数（N为阵元数）。RAD框架利用Fresnel分解的结构特性，将反馈量压缩为 O(1) 个实数标量：

  • 用户只需反馈距离 $R$ 和角度 $\theta$ 两个参数
  • 基站根据这两个参数直接计算聚焦权重，无需逐阵元反馈

这在大规模阵列场景下意义巨大，反馈开销从与阵元数线性相关降为常数级。以1024阵元系统为例，传统方案需反馈2048个复数（4096个实数），RAD方案仅需2个实数，压缩比达2000倍。

Fresnel近似下的相位展开

对远距用户（$R \gg D$），阵元到用户的距离可做二阶泰勒展开：

$$|\mathbf{r} - \mathbf{r}_n| \approx R - \mathbf{\hat{r}}\cdot\mathbf{r}_n + \frac{|\mathbf{r}_n|^2 - (\mathbf{\hat{r}}\cdot\mathbf{r}_n)^2}{2R}$$

  • 一阶项：对应远场平面波相位，产生角度 steering，形式为 $e^{jk\mathbf{\hat{r}}\cdot\mathbf{r}_n}$
  • 二阶项：对应近场球面波曲率，产生距离聚焦效应，形式为 $e^{-jk\frac{|\mathbf{r}_n|^2}{2R}}$

RAD方法的关键是将一阶和二阶项分离处理，而非像传统方法那样混在同一个 steering vector 里。这种分离使得预编码可以在两个独立域中分别优化。

多用户信道矩阵建模

考虑K个用户的近场XL-MIMO下行链路，基站配备N个阵元。第k个用户的信道向量为 $\mathbf{h}_k \in \mathbb{C}^{N \times 1}$，其第n个元素为 $[\mathbf{h}_k]_n = \frac{e^{-jk|\mathbf{r}_k - \mathbf{r}_n|}}{|\mathbf{r}_k - \mathbf{r}_n|}$。

RAD预编码矩阵 $\mathbf{W} = [\mathbf{w}_1, \mathbf{w}_2, ..., \mathbf{w}_K]$ 构造过程：

  1. 先计算每个用户的距离聚焦向量 $\mathbf{f}k = [e^{jk\frac{|\mathbf{r}_n|^2}{2R_k}}]{n=1}^{N}$
  2. 得到"拉平"后的等效信道 $\tilde{\mathbf{h}}_k = \mathbf{f}_k^* \odot \mathbf{h}_k$（逐元素相乘）
  3. 对 $\tilde{\mathbf{H}} = [\tilde{\mathbf{h}}_1, ..., \tilde{\mathbf{h}}_K]$ 应用ZF预编码：$\mathbf{W} = \tilde{\mathbf{H}}(\tilde{\mathbf{H}}^H\tilde{\mathbf{H}})^{-1}$

性能优势

仿真结果表明：

  1. 单用户速率：相比远场ZF，近场用户可获得显著相干增益，且增益随用户进入近场的深度增加而增大，近场深度用户增益可达5-8 dB
  2. 多用户调度：同角度不同距离的用户可以被有效分离，传统ZF无法处理的场景RAD可以解决，例如θ₁=θ₂但R₁≠R₂时，ZF的SINR趋近于0而RAD仍可保持良好隔离
  3. 反馈效率：O(1) 反馈 vs O(N) 反馈，在1024阵元场景下反馈开销降低约两个数量级
  4. 计算效率：O(N)的主计算量使得实时预编码可行，避免了O(N³)矩阵求逆的计算瓶颈

与硬件架构的配合

全数字波束赋形 + RAD 每个阵元独立配RF链路，RAD分解后的聚焦权重直接作用于数字预编码矩阵。精度最高，适合原型验证。每路RF链路的成本约为$50-100，1024阵元系统需约5-10万美元RF链路费。

混合波束赋形 + RAD 模拟域负责距离聚焦（TTD或相移器），数字域负责角度域零陷。工程可实现性强，但TTD的有限分辨率会引入误差。时延线分辨率通常为Δτ = 1/(B·N_TTD)，其中B为信号带宽，N_TTD为时延线级数。

子阵列 + RAD 将XL-MIMO划分为多个子阵列，每个子阵列独立执行范围聚焦，数字域做跨子阵列的角度协调。首尔国立大学2024年的子阵列方案可将波束训练时延从100ms降至1ms，与RAD结合后可进一步降低整体延迟。

与波束训练的结合

RAD框架天然适合低开销波束训练：

  1. 先做粗粒度角度扫描（远场codebook即可），使用传统远场码本搜索角度bin
  2. 再在选定角度bin内做距离扫描（一维搜索，复杂度远低于二维联合搜索），扫描步长建议ΔR = λ/4以保证距离分辨率
  3. 用户反馈 $(R, \theta)$ 后，基站直接计算RAD预编码权重

这比传统的二维码本穷举搜索（角度×距离）效率高得多。传统二维搜索需要N_θ × N_R个码本，而RAD方法仅需N_θ + N_R个探测符号。

与深度学习结合的方向

近年有研究尝试用神经网络替代RAD的两阶段优化：输入为信道状态信息（CSI），输出为预编码矩阵。这种端到端方法可在训练充分后实现毫秒级推理，但可解释性和泛化能力仍是问题。

1. 6G密集城区微站

小区半径 < 50m 时，大规模天线阵列的近场区域覆盖整个小区。同角度不同距离的用户（如30m vs 45m处）可通过LDMA分离，频谱效率提升显著。以28 GHz频段、128阵元系统为例，单用户速率可从1 Gbps提升至1.5-2 Gbps。

2. 室内高精度通信+定位

RAD框架的距离维度信息可直接用于定位。同一套预编码系统可同时提供通信和厘米级定位能力，与ISAC方向高度契合。定位精度理论上可达$\sigma_R \approx \frac{\lambda}{4\pi B \sqrt{SNR}}$，其中B为信号带宽，SNR为信噪比。在100 MHz带宽、20 dB SNR条件下，定位精度约3 cm。

3. 无人机编队通信

多架无人机在同一方位角但不同高度/距离，传统SDMA无法区分，RAD的LDMA能力恰好解决此问题。例如三架无人机位于同一方位角θ=30°，但距离分别为100m、150m、200m时，RAD可将三者的干扰对消到-30 dB以下。

4. 无蜂窝Cell-Free网络

多个AP协同服务用户时，每个AP的预编码都需考虑近场效应。RAD的低反馈特性使其特别适合AP间协作场景，每个AP仅需获取用户的(R,θ)即可独立计算预编码权重。

5. 工业物联网（IIoT）

工厂环境中大量设备密集部署，设备间距离差异大但角度可能相近。RAD的近距离高分辨率特性可有效分离这类场景中的干扰。

1. Fresnel近似的有效范围

二阶泰勒展开在 $R \gg D$ 时成立，但当用户非常靠近阵列（$R \sim D$）时，高阶项不可忽略。RAD框架在此区域的性能退化需要额外处理，建议在实际部署中设置最小聚焦距离限制，通常取 $R_{min} \geq 2D$。

2. 宽带信号的距离-角度耦合

上述推导基于窄带假设。宽带信号下，不同频点的聚焦距离不同，range-angle耦合更复杂。需要引入延迟-角度联合分解或频域分段处理。实际工程中，建议信号带宽不超过中心频率的10%，以保持窄带近似的有效性。

3. 信道估计的精度要求

RAD预编码依赖精确的 $(R, \theta)$ 估计。近场波束训练本身就是一个难题——角度+距离的联合搜索空间随阵元数平方增长。需要与低开销训练方案配合。实测表明，距离估计误差ΔR > λ/4时，聚焦增益下降超过3 dB。

4. 用户移动性

近场用户对距离变化敏感。沿径向移动会导致聚焦失配，需要快速跟踪机制。与波束倾斜补偿（TTD/DDP）结合是必要方向。建议设计自适应跟踪算法，更新周期T_update ≤ 1/(2f_D)，其中f_D为最大多普勒频移。

5. 多径环境下的鲁棒性

RAD假设视距主导信道，多径严重时会降低性能。实际部署需要考虑多径融合策略，如将主要径分离处理或多径加权合并。
