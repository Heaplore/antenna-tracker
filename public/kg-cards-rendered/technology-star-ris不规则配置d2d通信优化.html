STAR-RIS不规则配置D2D通信优化

台湾成功大学团队提出 STAR-RIS 不规则配置方案：只激活部分元素+2-bit低分辨率相移器+交叉熵优化，对数和速率提升52%、能效提升67%，为低成本D2D和IoT部署提供可行路径。

STAR-RIS 双模调控基础

STAR-RIS（Simultaneously Transmitting and Reflecting RIS）每个元单元同时具备透射和反射通道，满足能量守恒约束 $|\beta_n^t|^2 + |\beta_n^r|^2 \leq 1$，实现 360° 全空间覆盖。

不规则配置：稀疏激活

从 N 个元素中策略性选择 $N_s$ 个激活（$N_s \ll N$），搜索空间从 $2^N$ 降至 $\binom{N}{N_s}$，优势在于：

  • 降低硬件成本
  • 节省功耗
  • 增强空间分集（稀疏激活避免强耦合）

低分辨率相移器

采用 2-bit 量化（16个离散相位值），兼顾性能与实现复杂度。实际硬件中透射和反射系数存在耦合约束。

交叉熵优化框架（CEO）

针对混合连续-离散优化问题：

  1. 初始化概率分布
  2. 采样候选解
  3. 选择精英样本
  4. 更新分布参数
  5. 迭代收敛

避免陷入局部最优，复杂度低于穷举搜索。

用户调度分组

将 K 个 D2D 用户分成 $|\mathcal{G}|$ 组，同组共享时隙、不同组正交调度，减少组内干扰，提高频谱效率。

优化问题 formulation

$$\max_{\mathcal{S}, \boldsymbol{\Theta}, \mathbf{W}} \sum_{g \in \mathcal{G}} R_g$$

受限于：

  • 元素选择约束：$|\mathcal{S}| = N_s$
  • 功率分配约束：$|\beta_n^t|^2 + |\beta_n^r|^2 \leq 1, \forall n \in \mathcal{S}$
  • 相移器量化约束：$\theta_n \in {0, \pi/8, \pi/4, ..., 15\pi/8}$
  • 用户调度约束：每组共享时隙

交叉熵优化算法流程

1. 初始化: p_0(n) = 0.5, ∀n ∈ {1,...,N}
2. for t = 1 to T:

3.     采样: 从 Bernoulli(p_t) 采样 S^t
4.     评估: 计算 R(S^t), 选择 Top-k 精英样本
5.     更新: p_{t+1}(n) = mean(精英样本中 n=1 的比例)
6. end for

关键性能分析

  • 对数和速率增益：相比传统 RIS baseline 提升 52%
  • 能效增益：相比传统 RIS baseline 提升 67%
  • 硬件成本节省：仅需激活约 30-50% 的元素
  • 功耗降低：低分辨率相移器 + 稀疏激活双重节能

1. 车联网 V2X

D2D 是 V2X 核心使能技术。STAR-RIS 不规则配置降低车载终端功耗，适合高速公路和城市拥堵场景。

2. 物联网大规模连接

低分辨率相移器降低部署成本，不规则配置适配稀疏用户分布，分组调度支持海量设备接入。

3. 室内微蜂窝覆盖

部署于墙面实现全空间覆盖，不规则配置避免过覆盖干扰，D2D offload 缓解基站负载。

4. 应急通信网络

便携部署+D2D 自组网能力，不规则配置适应临时拓扑变化。

1. 元素选择与调度联合优化

$N_s$ 的选择和分组策略 $\mathcal{G}$ 需要联合优化，否则可能陷入次优解。

2. 低分辨率量化失真

2-bit 量化导致相位误差约 ±11.25°，在大规模阵列中累积误差可能显著。

3. 信道估计开销

不规则配置需要估计激活元素对应的子信道，信道估计开销随 $N_s$ 线性增长。

4. 动态拓扑适配

D2D 用户移动速度快，不规则配置需要快速重优化，实时性要求高。
