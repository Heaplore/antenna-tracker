高通RIS波束训练DCI信令设计

高通US12700912B2专利提出组通用+UE特定双阶段DCI框架，将RIS波束训练信令开销从O(N×M)降至O(N+M)，实现低开销高准确的波束对齐，是6G RIS标准化进程中最重要的信令层设计之一。

一、主题概述

高通公司于2026年8月4日获得授权的美国专利US12700912B2，提出了一种用于RIS波束训练的下行控制信息（DCI）设计框架。该专利是6G RIS标准化进程中最重要的信令层设计之一，解决了RIS辅助通信系统中波束训练开销大、控制信令复杂的核心难题。

问题背景： RIS辅助通信系统与传统的MIMO系统有本质区别：

  1. 三端信道：传统MIMO是BS-UE两点链路，RIS引入BS-RIS-UE级联信道，维度爆炸
  2. 被动波束成形：RIS无有源器件，需通过调控反射系数矩阵实现波束赋形
  3. 联合优化：需同时优化主动波束成形（基站发射波束）和被动波束成形（RIS反射系数）
  4. 训练开销：传统逐UE配置方式导致信令开销呈线性增长，无法扩展

专利核心价值：

  • 将波束训练分解为两个阶段，实现信令开销的阶数降低
  • 引入干扰管理机制，解决多UE场景下的训练干扰问题
  • 兼容现有5G NR物理层架构，可直接应用于6G标准化

RIS波束训练架构详解

传统MIMO波束训练 vs RIS辅助波束训练：

对比项 传统MIMO RIS辅助MIMO
信道类型 直接链路H_BS-UE 级联信道H_BS-RIS×Φ_RIS×H_RIS-UE
波束成形 仅主动波束成形 主动+被动联合波束成形
训练对象 BS和UE BS、RIS、UE三方协同
复杂度 O(N×M) O(N×M×K)（N:BS天线，M:RIS单元，K:UE数）

第一阶段：组通用RIS训练DCI - 一次性配置多个UE和RIS控制器 - 指示波束训练时隙分配 - 分配上行控制信道资源（PUCCH）用于反馈 - 降低控制信令开销

第二阶段：UE特定DCI - 针对单个UE细化训练参数 - 指示具体的波束训练occasion bitmap - 允许UE排除某些训练时隙以减少功耗

DCI字段设计详解

组通用RIS训练DCI关键字段：

字段 功能 典型长度 说明
Serving UE IDs 服务UE标识列表 动态 本次训练涉及的服务UE
Victim UE IDs 干扰UE标识列表 动态 需要测量干扰的UE
PUCCH资源指示 上行反馈信道资源分配 6-8 bits 反馈时频资源位置
波束数量指示 每个UE需报告的波束数 3-4 bits 通常2-4个最佳波束
干扰指标数量 干扰UE需测量的指标数 2-3 bits SINR下降值等
时频资源分配 训练信号资源的时频位置 动态 CSI-RS资源配置
RIS ID列表 参与训练的RIS控制器 动态 多RIS协同场景
训练 occasion 映射 时隙与RIS配置的对应关系 动态 时间域调度

UE特定DCI关键字段：

  • Bitmap指示：哪些波束训练时隙需要监测，减少UE功耗
  • Victim UE专用资源：干扰测量专用PUCCH资源
  • 训练时隙排除指示：允许UE跳过低质量时隙
  • 波束合并指示：是否允许UE合并多个时隙的测量结果

干扰管理机制详解

问题背景： RIS波束训练的关键挑战是训练信号对非目标UE的干扰。在密集部署场景下，多个RIS节点同时训练会产生严重干扰。

专利的双轨干扰管理设计：

轨道一：服务UE轨道 - 接收参考信号并测量波束质量 - 上报最佳波束索引和信道质量 - 反馈内容：波束索引、RSRP、SINR

轨道二：受害者UE轨道 - 测量RIS训练信号对其的干扰水平 - 上报干扰度量指标（如SINR下降值） - 反馈内容：干扰功率、SINR下降量

基站联合优化： 基站根据两类反馈联合优化RIS配置：

  1. 最大化服务UE的信道质量
  2. 最小化对受害者UE的干扰
  3. 实现训练精度与干扰抑制的平衡

干扰管理流程：

1. 基站发送组通用DCI，指示服务UE和受害者UE列表
2. RIS按照配置发射训练信号
3. 服务UE测量波束质量，上报最佳波束
4. 受害者UE测量干扰水平，上报干扰指标
5. 基站联合优化，发送UE特定DCI细化配置
6. 迭代优化直到收敛

信令开销分析

复杂度对比：

方案 信令开销 训练时隙数 反馈比特数 适用场景
传统逐UE配置 O(N×M) N×M N×K N,M小
专利组通用方案 O(N+M) max(N,M) N×K + M×J N,M大

其中：

  • N为服务UE数
  • M为RIS配置数
  • K为波束数
  • J为干扰指标数

具体数值示例： 假设N=100个UE，M=50个RIS配置，K=8个波束，J=4个干扰指标：

  • 传统方案：信令开销 = 100×50 = 5000单位
  • 专利方案：信令开销 = 100+50 = 150单位
  • 开销降低33倍

时延优势：

  • 传统方案：需5000个时隙完成训练
  • 专利方案：仅需max(100,50)=100个时隙
  • 时延降低50倍

6G RIS标准化核心支撑

3GPP标准化进展：

  • RAN1#121（2025年5月）：RIS相关讨论活跃
  • RAN2：RIS控制信道架构仍在博弈
  • 中国提案倾向：基于NCR架构演进
  • 欧洲提案倾向：全新RIS控制信道设计

专利框架的标准化价值：

  1. 兼容性：兼容现有5G NR物理层架构，可直接映射到RRC信令流程
  2. 灵活性：支持单RIS和多RIS场景，支持密集和稀疏部署
  3. 可扩展性：框架设计支持未来扩展，如更多UE、更多RIS配置
  4. 工程可行：提供了可落地的技术方案，非纯理论

密集城区RIS部署

场景特点：

  • 多个RIS节点密集部署
  • 用户密度高，多UE同时服务
  • 训练信号干扰问题突出

专利方案优势：

  1. 组通用DCI可同时配置多个RIS节点，减少控制信令时延
  2. 干扰管理机制保护非目标UE，提升整体性能
  3. 支持RIS协作波束赋形场景，实现多点协同

典型应用：

  • 城市微蜂窝覆盖增强
  • 热点容量补充
  • 室内外的无缝覆盖

车联网V2X场景

场景挑战：

  • 车辆高速移动导致信道快速变化
  • 需要低时延的波束追踪
  • 路侧单元RSU需要保护

专利方案优势：

  1. 低开销波束训练适应高移动性场景
  2. 干扰管理机制保护路侧单元RSU
  3. 支持RIS辅助的车载波束追踪

技术指标：

  • 波束追踪时延：<10ms
  • 训练开销降低：90%+
  • 干扰抑制：SINR提升5dB+

3GPP标准化博弈

RAN1讨论焦点：

  1. RIS控制信道架构：沿用5G NR还是全新设计
  2. 信令时延要求：亚毫秒级vs毫秒级
  3. 干扰管理策略：静默vs协调vs避让
  4. 标准化进度：R19还是R20纳入

中国提案倾向：

  • 基于NCR（Network Control Relay）架构演进
  • 与现有5G架构兼容
  • 强调工程可行性

欧洲提案倾向：

  • 全新RIS控制信道设计
  • 强调技术创新
  • 可能的标准分裂风险

趋势一：DCI-based RIS控制将成为6G标准主流

理由：

  1. 传统RRC信令时延过高（数百ms级），不适合RIS快速调控需求
  2. DCI直接在物理层传递，时延可降至符号级（<1ms）
  3. 高通专利框架的灵活性使其成为3GPP讨论的基础参考
  4. 与现有5G NR架构兼容，降低部署成本

时间线：

  • 2026-2027年：3GPP R19讨论和提案
  • 2027-2028年：R19标准冻结
  • 2028-2029年：设备厂商实现
  • 2029-2030年：商用部署

趋势二：干扰管理是RIS部署关键瓶颈

现状：

  • 多RIS协同场景下，训练信号干扰问题日益突出
  • 现有方案缺乏有效的干扰管理机制
  • 干扰管理直接影响系统容量和可靠性

专利方案价值：

  • 双轨干扰管理机制提供了实用解决方案
  • 预计将在R19/R20标准中被采纳
  • 为多RIS协同部署提供理论基础

后续发展：

  • 更复杂的干扰协调算法
  • AI辅助的干扰预测和规避
  • 动态干扰管理策略

趋势三：高通专利组合构成标准必要专利（SEP）风险

风险等级：高

原因：

  1. 高通在RIS控制信令领域已布局多项核心专利
  2. 专利覆盖从物理层到MAC层到RRC层的完整链条
  3. 专利框架灵活，易于覆盖标准必要技术
  4. 高通有强烈的专利许可动机

应对策略：

  1. 加速自身专利布局：在RIS控制信令领域布局替代方案专利
  2. 参与标准化：积极参与3GPP讨论，提出中国方案
  3. 技术储备：研究替代技术路线，降低对高通方案的依赖
  4. 交叉许可谈判：提前准备专利交叉许可谈判

趋势四：与中国NCR标准的竞合关系

技术路线差异： | 维度 | NCR方案 | RIS DCI方案 | |------|---------|------------| | 核心思想 | 有源中继增强 | 无源/半无源调控 | | 技术路线 | 传统架构演进 | 颠覆性创新 | | 标准化路径 | 中国主导 | 高通主导 | | 复杂度 | 较低 | 中等 | | 成本 | 较高 | 较低 |

共通之处：

  • 物理层控制逻辑上有共通之处（SCI侧链路控制信息）
  • 都需要解决信令开销和时延问题
  • 都可能成为6G标准的一部分

未来展望：

  • 两者可能在物理层控制逻辑上融合
  • 形成混合架构：NCR处理有源部分，RIS DCI处理无源部分
  • 中国厂商需准备多种技术路线
