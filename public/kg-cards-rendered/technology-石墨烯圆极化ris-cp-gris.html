石墨烯圆极化RIS-CP-GRIS

伊朗团队提出石墨烯基圆极化RIS，在266-332 GHz亚太赫兹频段实现双向波束扫描，峰值增益24.8 dBi，旁瓣抑制15.3 dB，为6G通感一体化提供低剖面圆极化波束赋形方案。

天线技术技术概念RIS石墨烯圆极化sub-THz6G

一、基本定义与原理

CP-GRIS（Circularly Polarized Graphene-based Reconfigurable Intelligent Surface）是一种基于石墨烯材料的圆极化可重构智能反射面，专为6G亚太赫兹通信设计。

核心创新点：将石墨烯的 tunable conductivity 与圆极化控制相结合，实现1-bit编码的2D/3D波束扫描。

工作原理：

  • 每个单元由倒置半月形金贴片（inverted semilunar-shaped gold patches）和嵌入式石墨烯条（graphene strip）组成
  • 石墨烯化学势调节改变表面电导率，产生约180°相位差的双稳态
  • 两个稳定相位态实现圆极化转换（RHCP/LHCP切换）
  • 45×45阵列形成大电尺寸孔径（15λ×15λ）

二、核心技术与公式

单元结构参数：

  • 基板：介电基板，光学厚度为奇数四分之一波长
  • 金贴片：倒置半月形，尺寸匹配266-332 GHz谐振
  • 石墨烯条：嵌入金贴片间隙，通过Gate电压调控费米能级

关键性能指标（300 GHz典型值）： | 参数 | 数值 | |------|------| | 峰值增益 | 24.8 dBi | | 波束宽度 | 4.4° | | 扫描范围 | ±40° | | 扫描损耗 | 1.2 dBi | | 旁瓣电平 | 主瓣下方15.3 dB | | 增益提升 | 12.4 dBi（vs馈源喇叭） | | 反射幅度 | >0.85 | | 相位差 | ~180° |

石墨烯调控机制：

σ_graphene(μc, T, τ) = (e²/πħ²) × (μc + 2k_BTln(e^(-μc/k_BT)+1)) × τ/(ħ²ω²τ²+1)

通过Gate电压调节化学势μc，实现从绝缘态到金属态的切换，产生180°相位跳变。

与已有RIS技术的差异：

  • 传统RIS：线性极化，单波束，固定方向
  • CP-GRIS：圆极化，双向切换，动态扫描
  • STAR-RIS：透射+反射双路，全空间覆盖
  • CP-GRIS：纯反射，但增益更高、旁瓣更低

四、应用场景

典型应用：

  1. 6G太赫兹回传链路：密集城市mmWave/THz基站间回传，圆极化抗多径衰落
  2. 卫星通信终端：低剖面可扫描天线，适配无人机/卫星平台
  3. 通感一体化：圆极化波束同时支持通信和高精度定位
  4. 抗干扰通信：圆极化天然抑制线性极化干扰源

与6G标准的契合度：

  • 匹配3GPP TR 38.901 UMa/UMi场景THz频段
  • 支持XL-MIMO近场波束聚焦的馈源增强
  • 为JCAS（联合通信与感知）提供硬件基础

六、工程挑战与坑

石墨烯RIS的固有挑战：

  1. 石墨烯迁移率：化学气相沉积（CVD）石墨烯迁移率通常1000-10000 cm²/Vs，限制调制速度
  2. 接触电阻：金属-石墨烯界面接触电阻影响损耗
  3. 批量制备：45×45=2025个单元的一致性要求极高
  4. 热管理：石墨烯功耗虽低，但亚太赫兹功率密度大，需散热设计

与老大研究的关联：

  • 本论文是被动RIS方案，老大关注有源RIS（ORIS）和逆拓扑设计
  • CP-GRIS的圆极化能力可补充STAR-RIS的极化维度
  • 1-bit编码效率（理论最大54%）远低于ORIS的连续相位调控（>80%）
  • 石墨烯调控速度与ORIS的PIN/HEMT方案对比值得研究

七、技术演进

  • 2020年：石墨烯RIS概念提出（单单元验证）
  • 2022年：THz石墨烯RIS综述发表（Yang et al., Micromachines）
  • 2024年：石墨烯RIS阵列实验验证（2×2至8×8）
  • 2026年6月：CP-GRIS全阵列（45×45）仿真与理论分析，Scientific Reports发表
  • 未来：实验验证、与ORIS/STAR-RIS融合、6G标准化
