MIT-HoNiBAJR反射面天线低功耗抗干扰卫星通信

MIT Lincoln Laboratory于2026年6月发布HoNi BAJR反射面天线原型，采用无源反射单元+单一馈源架构，功耗较传统相控阵降低95%，支持多峰波束合成和旁瓣区域抑制，专为pLEO战术卫星通信抗干扰场景设计。

一、主题概述

HoNi BAJR（Hosted Nimble Beamforming Anti-Jam Reflectarray）是MIT Lincoln Laboratory开发的扫描反射面天线原型，专为pLEO（大规模低轨卫星星座）环境设计。核心创新在于：信号在自由空间完成波束成形，所有单元反射信号汇聚到单一馈源天线，无需每个单元配备功率放大器。相比传统相控阵，功耗降低约95%，尺寸可适配典型小型卫星平台。

二、核心技术/原理

反射面天线 vs 相控阵：

特性 相控阵 反射面天线（HoNi BAJR）
单元结构 有源（含PA+移相器） 无源（仅相位调节）
功耗来源 每个单元独立PA 仅单一馈源PA
功耗水平 高（单元数×单功耗） 低（降95%）
波束切换速度 快（微秒级） 较慢（毫秒级）
适用场景 动态跟踪 计划性通信

抗干扰机制：

  • 旁瓣区域抑制：通过整形波束旁瓣创建"干扰抑制区域"，适应大规模快速变化干扰源
  • 多峰值波束合成：波束可分裂为多个峰值，同时服务多个用户
  • 自适应波束赋形：基于DESRa和PhAB项目技术积累，实时适应干扰环境

关键性能： | 指标 | 数值 | |------|------| | 功耗降低 | 约95%（vs 传统相控阵） | | 扫描角度 | 高扫描角（wide scan angle） | | 多波束能力 | 支持多峰值波束合成 | | 平台适配 | 典型小型卫星平台 | | 工作场景 | pLEO星座、强干扰环境 |

两条路线对比：

  • 银河航天：相控阵+ASIC路线（功耗降20%，速度快）
  • MIT：反射面路线（功耗降95%，适合静态部署）

五、趋势判断

  1. 反射面天线在卫星通信中复兴：随着pLEO星座对SWaP的极致追求，反射面架构重新获得关注，未来可能在小型卫星/立方星领域成为主流方案
  2. 抗干扰方法论转变：从"点对点null steering"到"区域化旁瓣抑制"，更适合pLEO大规模快速变化干扰场景
  3. 95%功耗降低的产业意义：同样卫星可搭载更多功能载荷，或更小卫星平台实现同等通信能力，直接贡献发射成本降低
  4. 与RIS/ORIS的技术交叉：反射阵列可编程相位控制理念与智能超表面高度相通，未来可能在同一硬件平台融合
